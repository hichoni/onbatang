# 온바탕 인수인계 · 이름 붙인 움직임 보관함

2026-11-03 · 공용 0.123.0 · 가이랩 0.177.0

## 사용 흐름

글 조각 선택 → **시네마 효과 / 효과 수정 → 화면 · 타임라인 편집**에서 꾸민 다음 **움직임 저장**을 누른다. 이름을 붙이면 문구·색감·강조색·배치·등장 순서·시간·효과별 설정을 함께 보관한다. 같은 이름도 새 프리셋으로 추가하며 기존 항목을 덮어쓰지 않는다.

- 편집기 효과 창의 **모든 내 움직임 보기**에서 다섯 종류의 프리셋을 함께 찾고 다른 효과로 전환할 수 있다.
- **내 움직임 보관함**과 장면 편집의 **보관함**에서는 현재 효과 종류의 프리셋을 찾는다. 갤러리 카드의 **내 내용으로 꾸미기**에도 이름 붙여 저장·보관함이 있다.
- 재생·멈춤·재생 위치 막대로 미리 본다. 자동 재생하지 않는다. 명시적 미리보기는 시스템의 동작 줄이기 설정에서도 한 번 재생할 수 있다.
- 기본값 **현재 글에 움직임만 적용**은 원래 글을 유지하고 배치·시간·색감을 가져온다. **저장한 문구도 함께 사용**은 효과 안의 문구까지 복사한다. 슬라이드 원래 글상자의 내용은 두 방식 모두 보존한다.
- **이 움직임 불러오기**는 초안에 반영한다. 이어서 **고른 조각에 적용 / 슬라이드에 적용**하면 문서에 저장된다. 장면 편집에서 불러온 프리셋은 실행 취소·다시 실행 대상이다.
- 이름 검색, 효과 종류별 보기, 이름 변경, 복제, 확인 후 삭제를 지원한다. 삭제는 보관함 항목에만 적용하며 이미 슬라이드에 복사한 효과는 남는다.
- 프리셋은 이 기기·이 사이트의 localStorage에 최대 60개 저장한다. 자동 계정 동기화는 하지 않는다. **보관함 파일 내려받기 → 파일 가져오기**로 공용·가이랩·다른 기기 사이에서 옮긴다. 가져오기는 기존 목록에 추가하고 같은 이름·효과·설정은 중복 추가하지 않는다.

현재 범위는 박자 오프닝, 스포트라이트 타이틀, 롤링 숫자, 종이 지평선, 탐사 항로다. 슬라이드 모핑·카메라 경로나 다른 일반 효과를 이 보관함에 담지는 않는다. 롤링 숫자는 현재 글에 유효한 숫자가 없으면 적용을 막고 저장한 문구를 쓰도록 안내한다.

## 보존과 저장 계약

- `src/motion-presets.js`: `onbatang-motion-presets-v1`, `{format:'onbatang-motion-presets',version:1,presets:[{id,name,effectId,options}]}`. 이름 40자, 전체 60개, 파일 500KB. 기존 `cinemaSettings`·`cleanCinemaTracks`로 허용 필드만 보관한다. HTML·이미지·URL·실행 코드는 보관하지 않는다.
- 저장 시 현재 문구를 `options.sceneText`로 명시해 원본 자료 없이도 미리보기가 가능하다. 문구 유지로 불러올 때만 sceneText 및 구절별 text를 제거하고 배치·시간을 복사한다.
- 매 쓰기 전 저장소를 새로 읽는다. 다른 탭의 추가를 오래된 목록으로 덮지 않는다. storage 이벤트로 열린 보관함을 갱신한다. 잘못된 파일·알 수 없는 버전·60개 초과·저장 공간 부족은 기존 내용을 바꾸지 않고 오류를 표시한다.
- `src/motion-preset-dialog.js`: 공통 이름 입력·관리·미리보기 UI. 재생 정지와 이벤트 해제, 모달 포커스 복귀. 한 번에 선택한 장면 하나만 그린다.
- 장면 편집에서 **움직임 저장**은 명시적인 별도 저장이다. 그 뒤 편집 취소를 눌러도 보관함에 저장한 프리셋은 유지되며 슬라이드 초안만 취소한다.
- 이전 효과별 단일 스타일 키는 변경·삭제하지 않는다. **이전 단일 스타일** 아래에서 계속 불러올 수 있다.
- 기존 문서 스키마·ID·원본 PPT·출처·활동·운영 DB 변경 없음. 기존 효과 옵션을 문서에 복사하므로 발표·저장·재열기·오프라인 HTML도 같은 설정을 사용한다. 프리셋 보관함 전체를 HTML 수업에 넣지는 않는다.

## 검증

- 단위 검사 418개. 새 검사는 복수 저장·복제·삭제, 기존 문구/구절 보존, 다른 탭 저장, 파일 병합·중복 제거, 값 제한, 잘못된 파일·새 버전·용량 부족 시 원본 보존을 확인한다.
- 브라우저 `named motion presets`: 갤러리에서 직접 고친 문구·배치·시간을 이름 붙여 저장 → 편집 취소 후 보관함 유지 → 새로고침 → 미리보기·멈춤·되감기 → 이름 변경·복제·삭제 → 파일 내려받기 → 새 브라우저 문맥에 가져오기 → 두 자료의 서로 다른 슬라이드에 문구 유지/포함 각각 적용 → 저장·재열기 → 보관함 삭제 후에도 적용한 효과 유지 → 발표 및 오프라인 HTML 재열기.
- 390×844, 844×390, 320×740 화면에서 보관함·미리보기·적용을 확인한다. 기존 장면 편집·타임라인·자체 제작 4:3 PPT 가져오기 회귀도 검사한다.
- 실제 개인 수업 PPT, 실제 휴대폰·태블릿, 실제 교사 계정 저장 검증은 이번 범위에서 별도 미완료다. 유료 QA·AI 호출·운영 DB 쓰기 없음. 브라우저 검사에는 새 격리 문맥과 자체 제작 자료만 사용한다.
- 최종 로컬/운영 확인 로그와 배포 커밋은 작업 폴더의 같은 이름 통합 인수인계에 기록한다. 공식 sync는 확정된 원본 Git blob으로 수행한다.
