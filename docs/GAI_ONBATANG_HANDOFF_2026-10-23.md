## 이번 실제 계정 검수 완료

검수 환경은 기존 운영 Supabase에 연결된 실제 교사 계정이다. 별도 QA 프로젝트나 새 교사 계정을 만들지 않았다. 원래 실과 PPT 파일은 19쪽이며 기존 앱/결과가 추가된 **26쪽·11파트** 기기 자료를 사용했다. 아래 전체 쓰기 흐름은 v0.115.0/공통0.70.0에서 수행했다. 검수 중 다른 작업의 v0.116.0/공통0.71.0이 병합돼 마지막에 로컬도 다시 fast-forward하고, 새 버전의 새 탭에서 저장 결과를 다시 열어 호환성을 확인했다.

1. 기존 로그인 상태의 인앱 브라우저에서 전체 자료 → **계정에 전체 PPT 백업**을 실행했다. 26쪽/11파트 완료 안내와 완료 목록 1건을 확인했다. 미완료 업로드를 완료로 세지 않았다.
2. 같은 계정으로 로그인된 **Edge의 분리된 브라우저 저장 공간**에서 내 계정 수업 → 내 계정 PPT → 미리보기 → 모든 파일 무결성 확인 → 이 기기에 복구를 실행했다. 파일이나 인증 세션을 수동 복사하지 않았다. 26쪽/11파트가 편집기로 열렸고 기존 20쪽 학생 PNG 2개·재편집한 답을 확인했다. 두 PNG data URL이 원래 브라우저와 정확히 같았다.
3. 복구한 자료로 **별도의 45분·5단계 검수 수업**을 저장하고 새 학생 참여방을 만들었다. 기존 만료 수업을 재시작하지 않았다. 교사 설명 쪽 이동이 학생의 2/13쪽으로 반영되고, 2/5단계의 기존 픽셀 앱이 학생에게 열렸다.
4. 학생 브라우저 3개가 참여했다. Chrome과 Edge 두 학생 화면에서 실제 버튼을 눌러 각각 **마지막 줄 3픽셀 / 첫 줄 2픽셀**을 그리고 제목·배운 점을 입력해 앱 완성 → PNG+답 제출을 마쳤다. 교사 연습 기록은 학생에게 이어지지 않았다. 일시정지 안내와 재개를 확인했다. 인앱 브라우저의 학생 A는 격리된 앱 입력 전달 제약으로 그림 제출을 하지 않았으며 3명 모두 제출했다고 보고하지 않는다.
