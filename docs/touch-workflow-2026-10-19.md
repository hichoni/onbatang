# 모바일·태블릿 PPT 작업 흐름 · 2026-10-19

공통 온바탕 v0.26.5의 변경과 검증 범위입니다. 유료 QA 프로젝트, 계정, 운영 DB를 사용하지 않습니다. 브라우저의 화면 크기·터치 입력 에뮬레이션과 실제 기기 검수는 구분합니다.

## 구현

- 내 자료의 PPT 가져오기에서 899px 이하 또는 높이 519px 이하인 화면은 상단 편집 도구를 간결하게 표시합니다. 짧은 가로 화면에서는 내용을 스크롤하며 가져오기 버튼에 접근합니다.
- 좁은 가져오기 영역에서는 큰 PPT 미리보기 → 쪽 목록 → 옵션 순서로 배치합니다. 파일·선택 쪽·글꼴 설정을 유지하며 화면을 회전하거나 다른 도구로 갔다 돌아올 수 있습니다.
- 글꼴 교체 창의 제목과 적용·취소 버튼은 고정하고 본문만 스크롤합니다. 휴대폰에서는 표를 글꼴별 카드로 표시하고 교체 글꼴과 적용 범위를 붙입니다. 태블릿에서는 표의 열 너비를 확보합니다.
- 터치 화면의 슬라이드 손잡이·이동 버튼·팔레트 슬롯·색상·삭제 버튼은 최소 44px입니다. 도구 목록은 가로로 밀어 이동하고 단순 탭과 스크롤을 구분합니다.
- 팔레트에 최근 색이 없을 때 표시되던 `null` 문자열을 제거합니다. 지원하지 않는 화면 스포이드는 기존 색 선택 창으로 안내합니다.
- 내려받기는 기존 스크롤 본문과 고정 확인 버튼을 유지하며 편집형·이미지형 PPTX를 모두 검증합니다.

## 보존 계약

자료·원본 파일·문서·자산·쪽 ID·원본 크기·전체 자료의 쪽 순서·저장 revision 계약을 변경하지 않습니다. 가져오기 중 도구로 이동하는 터치도 기존 호스트의 저장·종료 확인 경로를 거칩니다. 원본 PPT와 이전 고정본은 덮어쓰지 않습니다. 가이랩 내장본은 확정된 공통 commit을 공식 sync로 가져오며 호스트 고유의 글꼴 창에도 같은 레이아웃을 적용합니다.

## 검증과 남은 과업

검수 화면: 320×568, 390×844, 844×390, 768×1024, 1024×768, 880×640. 합성 PPT 21쪽의 가져오기·글꼴 교체·첫/마지막 쪽 이동·터치 드래그 순서 변경·팔레트 저장·새로고침 재열기·두 PPTX 전체 출력과 원본 불변을 검증합니다. 실제 수업 PPT의 원본은 로컬 비공개 `work/`에서만 다루고 저장소에 올리지 않습니다. 최종 실행 결과와 공개 배포 증거는 별도 QA 기록에 남깁니다.

실제 Android/iPhone/iPad, Safari, 운영체제 색 선택 창·화면 스포이드, 가상 키보드를 펼친 상태, 실물 기기의 회전·파일 앱 저장은 미완료입니다. 이 작업의 브라우저 에뮬레이션 성공을 실제 기기 성공으로 보고하지 않습니다. 로그인·메일·학생 계정·35명 동시 참여 및 유료 QA 환경은 이번 범위에 포함하지 않습니다. PPTX의 구조·쪽 수 검증과 PowerPoint에서 직접 여는 검수도 별도로 구분합니다.
