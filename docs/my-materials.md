# 내 자료 메뉴와 PPT 원본 비율 · 2026-10-19

v0.22.0은 [먼저 생성한 시안](design/my-materials-2026-10-19.md)을 바탕으로 편집기의 내 자료를 사진/PPT/유튜브로 정리한다. 사진이 기본이며 선택한 종류의 내용만 보인다. PPT 가져오기를 연결하지 않은 순수 편집기는 사진/유튜브 두 탭이다. 기존 저장소 이름·문서 스키마·원본·고정 revision·계정/가져오기 저장 계약은 바꾸지 않는다.

사진 올리기와 사진 목록, PPT 새 자료 가져오기, 유튜브 주소 입력을 각 탭에 둔다. 긴 사용 안내는 기본으로 접는다. 탭은 실제 tablist/tab/tabpanel과 존재하는 aria-controls/labelledby를 연결하며 방향키·Home/End를 지원한다. 같은 편집기의 다시 그리기에서 선택을 유지하고 새 편집기는 사진부터 시작한다. 파일 입력 노드와 입력 중인 유튜브 주소를 유지한다. 비동기 사진 처리 완료가 유튜브 주소 입력/자료 탭의 초점을 빼앗던 경계를 보완했다. PPT 가져오기 중에는 중복 이동과 탭 전환을 막는다.

## 원본 크기

기존 PPT 변환·저장·setupApp은 이미 원본 size/originalSize를 사용한다. 실제 배포 전 16:9·4:3·11:7 표본에서도 payload·전역 설정·실제 DOM 비율과 저장/재열기가 정확했다. 4:3·사용자 지정 크기는 기존 네 가지 프리셋에 없어 선택 표시가 비어 있던 것이 확인된 문제다.

상단에 실제 저장 치수에 따른 ‘원본 비율 · 4:3’ 등의 표시를 추가한다. 비표준 비율은 현재 선택 표시가 있는 읽기 전용 칩이며 프리셋에 임의로 반올림하지 않는다. 기존 네 가지 프리셋과 직접 비율 변경은 유지한다. 교사가 크기를 바꾸면 ‘현재 비율’로 표시하고 원본 크기 메타데이터는 보존한다. 실제 캔버스나 요소를 자동으로 다시 늘이거나 출처를 수정하지 않는다.

## 로컬 검증과 경계

최종 공통 전체 단위174/174·실제 Edge 전체20/20·정적 번들/CSP/입력·라이선스17파일 PASS다. 새 세 탭3개 회귀는 사진/주소/키보드/초점/390px/두 탭 연결과 busy를 검사한다. 새 원본 비율1개 회귀는 실제 worker의16:9·4:3·17:10 각2쪽, 정사각형과의 왕복, 저장/재열기와 편집형/이미지형 총6개의 정확한 sldSz를 검사한다. 기존16개와 신규4개를 같은 최종 전체20개 실행으로 확인했으며 앞선 반복 성공을 더하지 않는다.

처음 새 UI 회귀의 비동기 사진 초점 실패1건은 제품 결함으로 수정하고 실패 로그를 보존했다. 첫 전체 단위의 BUILD.json 해시 불일치는 편집 중 소스에 대한 이전 번들 입력 manifest가 남은 상태였으며, 제품 소스 동결 후 정식 재생성과 --check 및 전체174/174를 통과했다. 실제계정 QA·최신 출력의 직접 PowerPoint·물리 기기/35명/학교망은 별도 미완료이고 메일은 사용자 의사로 미실행이다. 공개 Firebase/가이랩 PR 미리보기와 실제 교사 PPT의 추가 로컬 검증은 후속 증거를 따른다.

공통 코드는 원본 저장소에서 관리하고 확정 commit의143파일을 가이랩 공식 sync로 반영한다. 공용 Firebase는 Hosting만 갱신하며 가이랩은 기존 PR 미리보기에 배포한다. 기존 PR #1/#76·교사 원본·운영 DB/SQL을 보존한다. 앱 release commit과 이후 문서/검증 기록 commit은 구분한다.

다음은 필요한 수업고/틴커랩 연결과 새 진입 경로의 별도 실제 계정 QA·학교 현장 검수다. 기존 실제 계정/PowerPoint 검증 기록을 이번 새 경로의 성공으로 계산하지 않는다.
