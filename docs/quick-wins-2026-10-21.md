## 만든 방식

- **PDF·인쇄**(`app/print.js`): 숨기지 않은 장마다 `designToBlob` 으로 PNG 를 만들고, 보이지 않는 iframe 에 인쇄용 HTML 한 벌(CSS `@page` A4 · `break-after: page`)을 쓴 뒤 `print()` 를 부른다. 그림 주소는 `blob:` 과 `data:image/png|jpeg` 만 받는다(스크립트 없음). 인쇄가 끝나면(또는 10분 뒤) iframe 과 blob 주소를 치운다. 노트 페이지는 파워포인트의 "노트 페이지"처럼 위 125mm 에 슬라이드, 아래에 노트.
- **숨긴 장**: 장의 `hidden: true`(`slideHidden` 이 저장·복사·정리하는 모든 곳에서 함께 펼친다). 발표(`present`)는 숨긴 장을 빼고 세되, 활동 결과를 저장할 때의 장 순서는 전체 순서를 쓴다. HTML 수업·PDF 도 뺀다. 모든 장을 숨기면 발표·HTML·PDF 가 안내만 띄운다.
- **찾아 바꾸기**(`app/find-replace.js`): 순수 함수. 정규식 특수 문자는 그대로 글자로 찾는다. 바꿀 글의 `$&` 같은 것도 글자 그대로 넣는다. 잠긴 요소는 찾지도 바꾸지도 않는다(캔바와 같다). 바꾼 글이 그 글상자의 글자 한도(`textLimit`)를 넘으면 그 글상자는 바꾸지 않고 수를 알려 준다. 바꾸기는 장 목록을 통째로 바꾸므로 되돌리기(Ctrl+Z)가 아니라 반대로 한 번 더 바꾼다고 안내한다. 여러 파트로 된 전체 자료에서는 지금 연 파트에서만 찾는다.
- **글 효과**: `lh`(0.5–4, 모든 글), `stroke`(색), `shadow`(true). 화면은 CSS `text-shadow` 하나로 그린다(테두리는 ±0.045em 8방향 고리, 그림자는 아래로 흐린 그림자). PNG·영상은 같은 DOM 을 그리므로 그대로 나온다. 편집형 PPTX 는 글자 윤곽선(`a:ln`, 글자 크기의 9%)과 바깥 그림자(`a:outerShdw`)로 쓴다.
- **그림 설명**: `alt`(한 줄, 300자). 화면의 `<img alt>`, PPTX `p:cNvPr@descr` 로 나가고 들어온다.
- 노트 칸 `spellcheck` 를 켰다(v0.35.1 README 의 "붙여넣기·맞춤법을 쓰도록" 과 맞춘다).

## 남긴 것

- 글 효과의 색은 흰·검정 두 가지만(사진 위 제목에 필요한 만큼). 더 고르게 할지는 써 보고 정한다.
- PPTX 를 가져올 때 글 윤곽선·그림자는 아직 읽지 않는다(지금처럼 "효과는 가져오지 않아요" 안내).
- 찾아 바꾸기는 한 번에 모두 바꾼다(하나씩 바꾸기는 없음).
