기존 PR #1과 브랜치를 보존하고 `flushSavedDesign(id)`를 추가했다. 활성 그림의 대기 중 자동 저장을 끝까지 기다리고 최신 기기 저장 레코드를 돌려준다. 전환 중·다른 그림·기기 저장 실패는 오류로 반환하고 편집 화면과 변경을 유지한다. 같은 그림의 동시 호출은 같은 저장 작업을 공유하며 저장 중 편집을 잠시 잠근다. 호스트의 계정 저장/CAS/SQL은 원본 앱에 넣지 않는다.

## 완료

- `src/document.js`와 `app/designs.js`: 문서·쪽·요소 ID, 원본/현재 크기, 출처, 자산 참조, 복제 계보를 allowlist로 검증하고 정리·JSON 저장·재열기에서 보존한다. 이전 자료는 안정적인 ID로 migration한다.
- IndexedDB v2: 이전 원문을 별도 저장하고, 열 수 없는 자료도 이유와 원문 내려받기를 제공한다. 지원하지 않는 버전·20쪽/40요소/120글자 한도 초과를 조용히 잘라 저장하지 않는다.
- 실제 4:3 화면, 쪽 이동/복사·문서 복사·움직임 일괄 적용에서 ID와 출처를 보존한다. 복사본에는 새 ID와 origin을 부여한다. 대상 문서에 없는 자산을 참조하는 붙여넣기는 변경 전에 안내한다.
- `app/samples/` 공통 표본, `importConvertedDocument`, 직접 제작 PPTX 세 종류와 원본 해시·예상 데이터. 자세한 범위는 [가져오기 경계](import-boundary.md)에 있다.

## 미완료와 다음 작업

공통 자산 참조는 논리 메타데이터다. 원본 파일의 비공개 업로드, 소유권, 고정 revision, 삭제 뒤 수업 자산 유지, 서버 충돌 처리는 호스트 T03 작업이다. 실제 PPTX/PDF 변환 worker·UI, 실제 교사 PPT/PowerPoint 렌더 비교, 학교 기기 검수는 미완료다. 예상 JSON은 변환기를 실행한 결과가 아니다.

계정 저장과 배포를 로컬 성공으로 간주하지 않는다. 이번 브랜치는 운영 main에 병합하지 않았다. 다음 세션은 최신 HEAD·미커밋 변경·호스트 PR 상태를 먼저 확인하고 T03에 맞춰 실제 변환 입력/결과 연결을 이어간다. 공통 편집기 변경은 이 원본에서 하고, 호스트 내장 파일을 직접 고치지 않는다.
