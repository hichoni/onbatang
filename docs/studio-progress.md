# 온바탕 공통 문서 기반 진행 기록

## 최신 후속 · v0.18.1 (2026-10-18)

실제 PowerPoint 편집 검수 중, 편집형 PPTX의 요소별 fallback PNG가 슬라이드 전체 크기의 투명 선택 영역을 가져 뒤의 글상자를 클릭하기 어려운 문제를 확인했다. 공통 원본 `app/pptx.js`에서 회전·뒤집기·마스크·투명도를 적용한 렌더 결과의 실제 alpha 범위만 잘라 원래 슬라이드 위치에 배치하도록 수정했다. 슬라이드 밖의 픽셀을 자르고 z-order·ID를 보존하며, 완전히 투명한 요소도 1×1 투명 그림으로 남긴다. 입력 문서와 원본 PPT를 수정하지 않는다. 기존 PR #1과 작업 브랜치를 유지한다.

공통 전체 단위 **152/152**, PPTX 단위 **15/15**, 실제 Edge exporter **1/1** 통과. 마스크·뒤집기·30° 회전·50% 투명도·화면 가장자리 잘림의 crop 재합성은 원래 전체 렌더와 비교해 허용 오차를 넘는 픽셀 차이 **0**이며, 잘못된 crop 좌표 거부와 완전 투명 요소의 크기·이름표 보존도 검증했다. 첫 Edge sandbox 실행은 브라우저를 시작하지 못했으며, 승인된 로컬 Edge 실행으로 통과를 확인했다.

실제 교사 PPT의 편집형·이미지형 각 **19쪽**을 새로 내려받아 Windows PowerPoint **16.0.20430.20182**에서 직접 열고, 복구 요구 없이 검수 사본의 편집·저장·닫기·재열기를 확인했다. 편집형은 회색 `#808080` 복원, 11쪽 제목 직접 선택, 화살표의 83×38px 개별 선택 영역을 확인했다. 글 덧붙이기와 화살표 이동 뒤 재열기·검색으로 수정 유지, 정확히 두 객체 변경, 다른 18쪽과 47개 그림의 미디어 바이트 유지를 검증했다. 별도의 수정 전 사본에서도 맑은 고딕 44pt 변경과 도형·사진 이동 세 객체의 저장·재열기가 통과했다. 최종 11쪽의 글자 넘침은 관찰되지 않았다. 이미지형은 쪽마다 한 그림이며, 11쪽 그림 이동·다른 이름으로 저장·재열기 후 19쪽과 그림 19개의 SHA-256이 유지됐다. 세부 증거 범위는 [PPTX 내려받기](pptx-export.md)에 기록한다.

남은 시각 차이는 10쪽 하단 강조 문장의 줄바꿈이다. 편집형 PowerPoint는 한 줄, 현재 온바탕 DOM과 이미지형은 두 줄이다. 원본 설치 글꼴이 실제로 사용됐지만 브라우저에서 프레임 943.438px보다 문장 너비 950.507px가 커 단어 단위로 줄바꿈된다. 원문·글자 크기를 임의로 줄이지 않았으며 Office와 브라우저의 글자 너비·줄바꿈 차이 검수를 후속 작업으로 남긴다. 원본 PowerPoint와 완전히 동일한 렌더 검증이 끝난 것으로 간주하지 않는다.

실제 QA 계정 저장·새 기기 복구는 별도 **미완료**이며, 로컬 PowerPoint·브라우저 성공이나 preview 배포로 대신하지 않는다. 교사 파일·본문·스크린샷·출력 사본은 비공개 로컬 검수 폴더에만 두고 커밋하지 않는다. 내장본은 호스트의 공식 동기화 절차로 이 원본 커밋·버전·파일 해시를 맞추며 실제 배포 확인은 호스트 진행 기록에서 구분한다.

## 최신 후속 · v0.17.0 (2026-10-18)

PPT 슬라이드의 긴 본문을 한 글상자에 4,096자까지 보존하고, 슬라이드의 사진은 최대 40장까지 보존한다. 일반 카드의 기존 글자/사진 한도는 유지하며, 요소 40개·문서 20쪽과 호스트의 512KiB 저장 한도도 유지한다. `layout:'slide'` 표식 또는 PPT 출처가 이 규칙을 적용하며, 출처를 제거한 학생용 보기에서도 공개 표식으로 유지된다. 본문을 임의로 문단 분할하지 않는다. 직접 만든 12사진·긴 본문 표본의 반복 정리·migration·복사·재열기와 4,096/4,097자·40/41요소·일반 한도를 검증했다. 공통 단위 137/137 통과.

원본 기기 글꼴을 등록된 편집기 글꼴보다 우선 적용하고, 사용자가 다른 글꼴을 고르면 원본 지정이 해제된다. 긴 PPT 본문 입력·붙여 넣기도 같은 한도를 사용한다. Windows의 설치 글꼴을 직접 지정해도 Edge가 대체 글꼴로 그리는 경우를 확인하여 학교안심 두 글꼴에 `@font-face src:local(...)` 연결을 추가했다. 파일을 복사하거나 네트워크에서 받지 않는다. 설치되지 않은 기기는 기본 글꼴로 표시된다. 가이랩의 실제 PPT·저장/재열기·배포 검증은 호스트 진행 기록을 따른다.

## 이전 후속 · v0.16.0 (2026-10-18)

교사 PPT를 가져온 뒤 작은 글씨가 커지고, 좁은 글상자와 얇은 구분선이 달라지는 문제를 공통 모델·렌더러에서 수정했다. PPT 요소의 치수는 소수 네 자리까지 유지하며 고정 글상자 높이·수직 정렬·줄간격·줄바꿈 여부·허용된 기기 글꼴 이름을 저장과 migration에서도 보존한다. 원본 출처를 숨긴 학생 화면은 공개 표시 속성 `layout:'slide'`로 같은 치수를 유지한다. 일반 편집 요소의 기존 최소 크기와 전체 문서 한도는 유지한다.

단위 **135/135**, 실제 Edge의 직접 만든 PPT 레이아웃 표본 **원본/내장본 각 1/1**, 기존 문서 왕복 **원본/내장본 각 1/1** 통과. 글자 크기·줄간격·두 줄의 실제 위치·얇은 선을 DOM에서 측정하고 기기 저장/즉시 저장/새로고침 재열기까지 확인했다. 변환기는 가이랩에서 관리하며, 실제 교사 원본 파일은 로컬에서만 검사한다. 실제 QA 계정/학교 기기/PowerPoint와 완전 동일한 렌더 검증은 별도 미완료다. 호스트의 `docs/onbatang-studio-progress.md`가 실제 PPT 지원 쪽 수와 배포 증거를 관리한다.

같은 세션의 실제 자료 검수에서 전용 글꼴 대체로 생기는 줄바꿈 차이를 확인했다. 사용자의 Windows에 설치된 `학교안심 이어달리기 L`을 기기 글꼴 이름으로 보존한다. 글꼴 파일은 복사·배포하지 않는다. 해당 글꼴이 없는 기기의 동일 배치는 별도 검수해야 한다.

## 완료

- `src/document.js`와 `app/designs.js`: 문서·쪽·요소 ID, 원본/현재 크기, 출처, 자산 참조, 복제 계보를 allowlist로 검증하고 정리·JSON 저장·재열기에서 보존한다. 이전 자료는 안정적인 ID로 migration한다.
- IndexedDB v2: 이전 원문을 별도 저장하고, 열 수 없는 자료도 이유와 원문 내려받기를 제공한다. 지원하지 않는 버전·20쪽/40요소/120글자 한도 초과를 조용히 잘라 저장하지 않는다.
- 실제 4:3 화면, 쪽 이동/복사·문서 복사·움직임 일괄 적용에서 ID와 출처를 보존한다. 복사본에는 새 ID와 origin을 부여한다. 대상 문서에 없는 자산을 참조하는 붙여넣기는 변경 전에 안내한다.
- `app/samples/` 공통 표본, `importConvertedDocument`, 직접 제작 PPTX 세 종류와 원본 해시·예상 데이터. 자세한 범위는 [가져오기 경계](import-boundary.md)에 있다.

## 미완료와 다음 작업

공통 자산 참조는 논리 메타데이터다. 원본 파일의 비공개 업로드, 소유권, 고정 revision, 삭제 뒤 수업 자산 유지, 서버 충돌 처리는 호스트 T03 작업이다. 실제 PPTX/PDF 변환 worker·UI, 실제 교사 PPT/PowerPoint 렌더 비교, 학교 기기 검수는 미완료다. 예상 JSON은 변환기를 실행한 결과가 아니다.

계정 저장과 배포를 로컬 성공으로 간주하지 않는다. 이번 브랜치는 운영 main에 병합하지 않았다. 다음 세션은 최신 HEAD·미커밋 변경·호스트 PR 상태를 먼저 확인하고 T03에 맞춰 실제 변환 입력/결과 연결을 이어간다. 공통 편집기 변경은 이 원본에서 하고, 호스트 내장 파일을 직접 고치지 않는다.
