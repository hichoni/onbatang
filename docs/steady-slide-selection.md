# 슬라이드 선택 화면 안정화 · v0.26.3

PPT 쪽을 고를 때의 흔들림은 목록 중앙 정렬, 파트 이동 시 전체 편집기 재생성/초기 파트 목록 표시, 목록 안 로딩의 높이 변화, 쪽 진입 애니메이션이 겹쳐 발생했습니다.

목록의 쪽 ID를 기준으로 썸네일 DOM을 유지하고 선택 표시만 갱신합니다. 보이는 쪽을 선택하면 가로 위치를 그대로 둡니다. 화면 밖의 쪽만 목록 가장자리까지 최소 이동합니다. 순서/쪽 구성 변경 때는 필요한 목록을 갱신하고 이전 드래그 이벤트 연결을 해제해 중복 저장을 막습니다.

파트를 바꿀 때는 현재 그림 저장 성공과 목표 쪽 ID를 확인한 후 같은 편집기 객체의 문서·쪽·자산 목록을 교체합니다. 화면 틀·목록·스크롤은 유지하고 새 문서의 이름·비율·저장 대상을 갱신합니다. 저장 실패 때는 기존 문서와 편집 이력을 유지합니다. 로딩은 캔버스 위의 비배치 요소로 표시하며 편집 중 선택에는 진입 애니메이션을 사용하지 않습니다. 발표 효과는 유지합니다.

합성 21쪽/2파트의 브라우저 검증은 쪽 선택 중 화면/목록/썸네일 DOM, 목록 높이와 세로 위치, 가로 스크롤, 모바일 페이지 스크롤을 확인합니다. 첫/마지막 파트의 수정·실패 시 보존·저장/재열기·전체 PPTX·드래그/팔레트의 기존 검증도 함께 실행합니다. 실제 19쪽 PPT는 로컬에서만 읽고, 전체 쪽 탐색 동안 매 프레임 화면 위치와 높이를 비교합니다.

이번 수정은 QA DB·계정·운영 SQL을 사용하지 않습니다. 로컬 검증과 공개 서비스 확인은 구분하며 실제 기기/계정 검수는 별도입니다. 실제 배포 commit과 결과는 완료 기록에 남깁니다.
