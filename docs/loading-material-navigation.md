# 심벌 로딩과 전체 PPT 편집 · v0.25.0

온바탕의 녹색·살구색·크림색 심벌 조각이 서로 다른 방향에서 다가와 완성된 뒤 잠시 머무는 애니메이션이다. `app/loading.js`가 공통 DOM을 만들고 `app/app.css`가 움직임과 정지 모드를 제공한다. 외부 이미지·폰트·서버 호출을 추가하지 않는다. PPT 검사·미리보기·저장·보관함과 내 그림 목록에 같은 표시를 사용한다. 실제 저장된 쪽 수가 보고될 때만 진행 막대를 표시하며, 취소·오류·완료 때 진행 상태를 해제한다. 화면 전체를 가로막는 모달 로딩은 만들지 않는다.

19쪽 자료가 여러 파트로 저장되어도 첫 파트에 한 쪽만 있으면 기존 편집기는 `1 / 1장`만 표시했다. 저장된 전체 자료를 한 문서에 다시 합치지 않고, 공통 편집기의 선택적 `materialNavigation.load({designId})`에 `{title, documents:[record, …]}`를 제공해 모든 쪽을 하나의 띠에서 표시한다. 현재 파트의 미저장 편집을 띠에 즉시 반영하고, 다른 파트 이동은 현재 기기 저장과 해당 계정 정책의 저장 성공을 먼저 확인한다. 실패하면 현재 화면과 편집을 유지한다. 이 계약에는 계정 SDK나 DB 스키마가 포함되지 않는다.

독립본은 기존 자료 묶음의 정확한 파트를 읽고, 편집 초안이 없을 때만 원본 고정본에서 초안을 만든다. 이미 존재하는 초안은 덮어쓰지 않는다. 가이랩은 자신의 자료 저장소·초안 기준 계약으로 같은 인터페이스를 제공한다. 새로고침 후 내 그림에서 파트를 열어도 전체 자료 목록을 다시 연결한다. PPTX ‘모든 장’은 각 파트의 현재 기기 편집본을 순서대로 모아 내보내며 고정 revision을 새로 쓰지 않는다. 서로 다른 화면 비율을 하나의 PPTX로 조용히 합치지 않고 오류를 알린다. PNG·JPG·영상과 장 복제·이동 도구는 기존 현재 파트의 범위를 유지한다.

합성 21쪽 브라우저 검증은 로딩의 세 조각·정지 설정·모바일 넘침·파트 이동·저장 실패 시 보존·새로고침 복구·두 PPTX 방식의 전체 21쪽 출력을 확인한다. 실제 교사 19쪽 검수의 원본·화면·출력은 `work/`의 Git 제외 경로에서만 다루며 공개 보고서에는 결과·해시·개수만 기록한다. 실제 계정 QA·새 기기·35명·다른 기기의 PowerPoint 렌더는 별도 검증 범위다. 공개 배포 여부와 로컬 검증도 구분한다.
