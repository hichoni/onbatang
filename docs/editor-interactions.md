# 편집 조작과 단축키 — 2026-10-18

사용자 요청에 따라 기본 모서리 끌기의 중심 기준·강제 비율 확대를 고친다. 저장 스키마와 치수 한도를 바꾸지 않고 현재 요소의 치수·ID·출처·내용과 실행 취소를 보존한다. 위치 x/y만 소수 네 자리까지 보존해 화면1px 이동과 고정한 모서리가 저장 후 반올림으로 움직이지 않게 한다. 제품 안내에는 온바탕에서 실제 지원하는 조작만 표시한다.

## 적용 규칙

| 조작 | 동작 |
|---|---|
| 단일 요소 모서리 끌기 | 잡은 방향으로 너비·높이 조절, 반대 모서리 고정 |
| Shift + 모서리 | 가로세로 비율 유지, 반대 모서리 고정 |
| Ctrl + 손잡이 | 중심을 고정하고 양쪽으로 조절 |
| Ctrl + Shift + 모서리 | 중심과 비율을 함께 유지 |
| 변 손잡이 | 해당 축만 조절하고 반대 변 고정 |
| 방향키 / Shift + 방향키 | 보이는 편집 화면 기준 1px / 10px 이동, 가로·세로 축별 치수로 환산 |
| Ctrl + Z / Ctrl + Y 또는 Ctrl + Shift + Z | 실행 취소 / 다시 실행 |
| Ctrl + D / Ctrl + G / Ctrl + Shift + G | 복제 / 그룹 / 그룹 해제 |

일반 글상자는 글자 크기를 유지하고 너비를 바꾸며 내용에 따라 높이가 정해진다. PPT의 고정 높이 글상자는 상자 치수도 조절한다. Shift 모서리 조절은 글자 크기도 함께 확대·축소한다. 이모지는 고유 비율을 유지한다. 여러 요소를 함께 고른 묶음의 크기 조절은 기존처럼 비율을 유지하며 반대 모서리를 고정하고, Ctrl을 누르면 묶음 중심을 기준으로 조절한다. 사진의 원본 픽셀을 변형하거나 덮어쓰지 않으며 기존 사진 틀의 맞춤 규칙을 따른다. 회전한 요소는 회전 전의 가로·세로 방향으로 증분을 계산한다. 작은 요소의 넉넉한 선택 테두리에서 잡아도 시작 시 치수가 튀지 않아야 한다.

기존 최대·최소 치수와 위치 제한을 유지한다. 한계에 닿으면 무한히 확대하거나 음수 크기로 뒤집지 않는다. 기존의 왼쪽/위쪽 변 손잡이 추가, Shift 이동의 축 고정, 손잡이 직접 키보드 조절·숫자 치수 입력은 후속 범위다. 이번 구현에서 완료한 것으로 계산하지 않는다.

## 조사 근거와 차이

2026-10-18 공식 안내를 확인했다. Windows PowerPoint는 Ctrl 중심 유지, Shift 모서리 비율 유지, Ctrl+Shift 결합을 안내한다. 이번 모서리 정책은 이 규칙과 사용자의 요청을 기준으로 정했다. Microsoft의 Mac 안내는 중심 유지 키가 Option이므로 플랫폼별 규칙이 모두 같다고 설명하지 않는다. [Microsoft 크기 조절](https://support.microsoft.com/en-au/office/graphics-visuals/change-the-size-of-a-picture-shape-text-box-or-wordart).

미리캔버스 새 에디터는 방향키 1px·Shift 방향키 10px와 복제·그룹·다시 실행 조합을 명시한다. 온바탕의 기존 방향키 1%·Shift 5%는 큰 점프였으므로 화면 픽셀 기준으로 바꾼다. 이 공식 표에서 일반 모서리의 Shift/Ctrl 정책까지 확인한 것은 아니다. [미리캔버스 새 에디터 단축키](https://help.miricanvas.com/hc/ko/articles/46839726702873-%EC%83%88%EB%A1%9C%EC%9A%B4-%EC%97%90%EB%94%94%ED%84%B0-%EB%8B%A8%EC%B6%95%ED%82%A4-%EC%95%88%EB%82%B4).

Canva는 사진 자르기 모드에서 Shift로 비율을 해제하는 조작과 일부 그래픽의 고정 비율을 안내한다. 온바탕의 Shift 정책이 Canva와 동일하다고 주장하지 않는다. 일반 단축키 표의 전체 키 목록은 이번 읽기에서 확인하지 못했다. [Canva 크기·자르기](https://www.canva.com/help/resize-and-crop/).

로컬 브라우저·저장 검증과 실제 계정·학교 기기 검증은 진행 기록에서 구분한다.
