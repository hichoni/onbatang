# 활동·앱 제작의 호스트 분리 · 2026-10-20

공용 온바탕 v0.30.2는 픽셀아트 활동 넣기·가이X 앱 만들기·활동 설정을 제공하지 않는다. 기존 문서에 저장된 활동·앱은 발표 안에서 계속 실행하며 상태·결과 저장, 다음 쪽 결과 삽입, 재열기, HTML 수업과 결과 반환을 유지한다. 숨김은 기존 활동 데이터를 지우거나 변환하는 migration이 아니다.

`startMinican`/`startOnbatang`의 실행 옵션 `activityAuthoring`은 기본값이 `false`이다. 제작 호스트인 가이랩만 `activityAuthoring:true`로 시작한다. 가이X 제작은 여기에 기존 `appMaker` 연결까지 필요하다. 픽셀아트 제작은 AI 연결 여부와 무관하다. 제작 진입 함수도 같은 옵션을 검사한다. 발표·checkpoint·결과 저장 경로는 이 옵션에 의존하지 않는다.

문서 스키마·SQL·저장소 이름·앱 sandbox·계정 동기화는 변경하지 않는다. 공용 PPT와 가이랩 PPT의 저장은 기존 기기 저장 경계를 유지하며 계정 백업을 새로 보장하지 않는다.

## 검증

- 공통 단위 검사 203/203 통과.
- 자체 제작 21쪽 PPT를 실제 worker로 변환하고 명시적 제작 테스트 호스트에서 픽셀아트를 추가한 뒤, 실제 공용 진입점으로 돌아가 제작 버튼·설정이 없는 상태에서 참여·결과 저장·재열기·HTML 및 편집형/이미지형 PPTX 내보내기 통과.
- HTML 수업 결과 반환을 1440px·390px에서 공용 기본 진입점으로 검사: 미리보기·새 고정 저장·재열기·중복 방지 통과.
- 가이X 모의 공급자로 앱을 만들고 수정한 뒤 공용 기본 진입점으로 재열기: 제작·설정 숨김, 기존 앱 실행·checkpoint·결과 저장·재열기 1440px·390px 통과. 실제 AI 요청은 하지 않았다.
- 위 브라우저 검사는 로컬 자체 제작 표본이다. 실제 계정·실물 모바일/태블릿·35명 동시 참여 검수로 보고하지 않는다. 운영 배포 확인과 가이랩 검사 결과는 최신 인수인계 문서에 별도로 기록한다.

원본 교사 PPT·기존 PR·운영 DB·과금 설정을 보존하며 유료 QA 환경을 사용하지 않는다.
