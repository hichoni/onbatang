# HTML 모션 에셋

## 두 장 비교

발표 막대의 **비교**를 누르거나 **D**를 누른다. 기준 장과 비교할 장을 각각 고른다. **커튼**은 경계선을 밀어 달라진 곳을 드러낸다. **포개기**는 두 그림의 진하기를 섞어 같은 자리의 움직임을 보여 준다. **나란히**는 화면 폭에 맞춰 좌우 또는 위아래로 놓는다. 각 장의 원래 비율을 유지한다. [그림자와 축제 안내도로 체험](../app/effects.html#slide-compare)

커튼이나 포개기에서 **이 위치 기억**을 누르면 현재 비교하는 두 쪽에 최대 세 위치를 표시한다. 번호를 누르거나 **PageUp / PageDown**으로 되짚는다. 같은 쪽에서 비교를 닫았다 열면 이어지며, 다른 쌍을 고르거나 발표를 끝내면 위치를 비운다. 비교 중 자동 넘김은 기다리고, 닫으면 원래 발표하던 쪽에서 이어진다. 활동과 단계별 정답이 있는 쪽은 비교 목록에서 제외한다. PPT에서는 발표 번호와 원본 번호를 함께 표시한다. 내려받은 HTML은 **발표 모드 → 비교**에서 같은 도구를 연다.

첫 화면 **틀로 시작하기 → 디자인 세트**에 두 가지 5장 자료가 있다. **그림자 관측소**는 같은 막대의 아침·한낮·오후 그림자를, **학교 축제 길찾기**는 같은 지도에 경로 표식이 더해지는 과정을 보여 준다. 제목, 도형, 안내문, 발표자 노트를 수정할 수 있다. **움직임 → HTML 그래픽 효과**에서 기존 조각에도 **햇빛의 호**와 **길찾기 표식**을 붙일 수 있다.

## PPT 글상자로 단서 카드 만들기

1. 수업 자료에서 정답으로 쓸 80자 이하 글상자 하나를 선택하고 **글 → 단서 카드 만들기**를 누른다. **움직임 → HTML 그래픽 효과 → 단서 카드**에서도 같은 편집 칸을 연다.
2. 질문 한 줄과 선택 힌트 최대 세 줄을 쓴다. 빈 힌트는 건너뛰며, 모두 비우면 질문에서 바로 정답으로 넘어간다. **장이 열릴 때**를 고르면 발표 중 글상자를 누르기 전에 질문이 펼쳐진다. 한 장에 자동 질문이 여러 개라면 첫 카드가 먼저 열리고 나머지는 교사가 눌러 연다. **고른 조각에 적용**을 눌러 저장한다.
3. 발표에서 질문을 읽고 답을 기다린다. **다음**은 힌트를 하나씩 공개하고 마지막에 글상자의 현재 내용을 보여 준다. 학생이 먼저 맞혔으면 **정답 바로 보기**를 누른다. 질문 문장은 단서와 정답 위에 계속 보인다. **이전 단계**를 누르면 앞 단서를 다시 볼 수 있다. 키보드 방향키, PageUp·PageDown, 발표 리모컨의 앞뒤 명령도 열린 카드에서 같은 순서로 작동한다. 첫 단계에서 뒤로, 마지막에서 앞으로 가면 카드가 닫힌다.

초성·차트·사진 질문도 이전 단계로 돌아갈 수 있다. 질문이 있는 장에서는 자동 넘김이 교사의 조작을 기다린다. 내려받은 HTML은 인터넷 없이 같은 질문과 단서를 실행한다. 이 기능에서 학생 답은 말로 듣는다. [픽셀 수업 예시 재생](../app/effects.html#clue-card)

## 움직이는 디자인 세트

첫 화면 **틀로 시작하기 → 디자인 세트**에서 ‘모션 5장’ 표지를 고르면 편집할 수 있는 다섯 장이 새 자료로 열린다. 세트를 고르기 전에 미리보기를 열어 다섯 장을 앞뒤로 넘길 수 있다. [여섯 세트 발표 미리보기](../app/effects.html#motion-stories)

| 세트 | 장 사이에 이어지는 움직임 | 요소에 따로 붙일 수 있는 효과 |
| --- | --- | --- |
| 해를 가리는 달 | 달이 해 앞을 가로질러 빛의 고리가 남는다 | 일식의 광환 |
| 우리 학교 레코드 | 음반의 표식이 돌고 바늘이 안쪽 홈으로 이동한다 | 음악의 맥박 |
| 씨앗 관찰 수첩 | 확대해 본 씨앗이 땅에 놓이고 뿌리와 잎이 자란다 | 잎맥 그리기 |
| 세 컷 영화제 | 필름의 풍경·문·인물을 따라 상영 위치가 바뀐다 | 조리개 셔터 |
| 두 색 인쇄실 | 어긋난 두 색판이 기준점에서 포개진다 | 색판 맞추기 |
| 바통이 지나간 자리 | 바통이 교대 구간을 거쳐 결승선에 닿는다 | 결승선 질주 |

각 장의 제목과 질문, 그림을 이루는 도형, 발표자 노트를 고칠 수 있다. 온바탕 발표는 대응하는 도형의 위치와 크기를 장 사이에서 잇는다. 제목을 누르면 강조 효과가 재생되며 네 번째 장에서는 자동으로 재생된다. 내려받은 HTML 수업은 슬라이드를 이미지로 보관하고 제목의 강조 효과를 별도로 재생한다. 동작 줄이기를 설정한 기기에서는 효과의 정지 화면을 보여 준다.

## 사진 속으로 들어가기 · 실과 수업 장

PPT에서 사진이 보이는 장을 열고 **움직임 → 사진 속으로 들어가기 · RGB 수업**을 누른다. 현재 장을 보면서 관찰할 점을 찍고, 필요하면 방향키로 한 픽셀씩 옮긴 뒤 **다음에 수업 장 넣기**를 누른다. 새 장은 그 쪽 바로 뒤에 들어간다.

발표의 다음 단추나 리모컨으로 사진을 확대하면 질문에서 멈춘다. 다음을 한 번 더 누르면 RGB 세 값이 보인다. **이 색으로 그리기**로 넘어가면 8×8 그림판의 왼쪽 위 칸과 첫 물감에 같은 색이 들어간다. **결과를 다음 슬라이드에 저장**하면 그림이 PNG 요소가 되어 수업에 남는다. HTML 수업도 이 과정을 오프라인에서 실행한다. 관찰 대상은 수업 장을 만들 때 저장한 슬라이드 미리보기의 한 픽셀이다. [샘플로 체험하기](../app/effects.html#photo-study)

HTML 장면을 입력값과 함께 재사용하는 HyperFrames의 구성 방식을 참고했다. 온바탕의 입력은 교사의 슬라이드, 선택 좌표, 픽셀 색이다. 수업 중 질문에 머무는 시간은 발표자가 정한다. [HyperFrames의 장면 구성 문서](https://hyperframes.heygen.com/concepts/compositions)

참고 영상의 제작자는 같은 대본과 촬영분에 서로 다른 모션을 적용했다. 2분 28초부터 도입 장면을 비교하고, 3분 8초부터 진행 막대와 깊이감이 있는 카메라 이동을 비교한다. 온바탕은 이 중 같은 대상을 따라가는 카메라 이동을 사진 관찰에 적용했다. [도입 장면 비교](https://www.youtube.com/watch?v=fvvRCpCFJYk&t=148s) · [카메라 이동 비교](https://www.youtube.com/watch?v=fvvRCpCFJYk&t=188s)

편집기에서 글·도형·그림·차트 하나를 고른 뒤 **움직임 → HTML 그래픽 효과**를 연다. 에셋을 눌러 미리 보고 속도와 색감을 정한다. **고른 조각에 적용**을 누르면 자료에 저장된다. 발표와 내려받은 HTML 수업에서는 요소를 누르거나 키보드로 초점을 옮겨 Enter 또는 Space를 누른다. [열여덟 가지 효과 예제](../app/effects.html)

**질문하고 단계별 공개** 효과는 발표할 때 조각을 가려 둔다. 교사가 단서를 공개하는 동안 같은 장에 머문다. 입력한 설명은 마지막 단계에 나타나며 **처음부터**를 누르면 다시 가려진다.

| 효과 | 고를 조각 | 발표에서 해 볼 일 |
|---|---|---|
| 미스터리 렌즈 | 사진 | 작은 창에서 보이는 단서를 말해 보고, 렌즈를 넓힌 뒤 전체 그림을 확인한다. 내려받은 HTML에서는 이미 저장된 슬라이드 그림의 해당 영역을 사용한다. |
| 다음 점 예측 | 항목이 두 개 이상인 꺾은선 차트 | 첫 관측값을 보고 다음 값을 예측한다. 한 번 누를 때마다 다음 시점의 실제 값이 모든 계열에 함께 나타난다. |
| 초성 해독기 | 한글이 든 16자 이하 글 | 초성에서 수업 낱말을 추측하고 첫 글자와 정답을 차례로 공개한다. 한 음절인 낱말은 정답으로 바로 넘어간다. |

발표용 표시를 가리는 기능이다. 배포한 HTML에는 수업에 사용할 그림과 정답 데이터가 들어 있다. PPTX 및 정지 이미지 출력에는 단계별 재생이 포함되지 않는다.

**키네틱 타이틀**은 선택한 글의 첫 72자 이내를 큰 화면에 낱말 단위로 표시한다. **데이터 포커스**는 선택한 세로·가로 막대 차트의 항목·계열·단위·값을 읽는다. 음수와 양수는 공통 0선에서 반대 방향으로 자란다. 같은 장에 자동 강조 화면이 여러 개면 차례로 보여준다. 클릭으로 연 강조 화면은 직접 닫거나 다음 장으로 이동할 때까지 유지한다.

## 재사용

조각에는 효과 ID와 재생 시점을 저장한다. 속도, 팔레트, 설명은 선택 사항이다. 자료를 고치면 새 글과 차트 값이 다음 발표와 HTML 내보내기에 적용된다.

```js
{ effect: { id: 'signal', when: 'press', pace: 'slow', palette: 'sunset', note: '전기가 흐르는 길' } }
```

`src/effect-assets.js`의 `EFFECT_ASSETS`에서 ID·이름·팔레트·그리기 함수를 관리한다. `effectArt(id)`는 정지 SVG를, `effectArt(id, true, {content, pace, palette})`는 한 번 재생하는 SVG를 돌려준다. 동작 줄이기 설정에서는 정지 그림을 쓴다. 조각 장식은 `prism`, `orbit`, `signal`, `confetti`, `underline`, `constellation`이다. `kinetic`과 `bars`는 선택 조각의 내용으로 강조 화면을 그린다.

임의의 HTML 무대에 기존 요소와 동작을 연결하려면 `src/effect-player.js`의 `mountEffectPlayer(stage, [{node, effect, content}])`를 호출한다. 강조 화면에 쓸 `content`에는 해당 온바탕 조각을 전달한다. 장식 효과에는 생략해도 된다. 무대의 CSS 위치는 `relative`로 두고, 장을 떠날 때 반환된 정리 함수를 호출한다. 설명은 일반 텍스트로 표시한다.

## 재생 및 검증 범위

편집기, 발표, HTML 수업에 같은 렌더러를 사용한다. HTML 수업에는 슬라이드 그림, 조각의 위치·크기·회전, 효과 실행 코드를 파일 하나에 넣는다. PNG·PDF·PPTX 출력의 애니메이션 변환은 별도 작업이다.

로컬 브라우저 회귀 시험은 `tests/browser/html-effect-assets.test.mjs`다. 공용 원본에서 실행하고, 내장본에서는 `MINICAN_HOST_ROOT`를 가이랩의 `dist`로 지정한다. 임시 프로필의 자료로 저장·재열기, 편집기와 발표의 클릭, HTML 내려받기, 모바일 폭 오프라인 재생을 확인한다.
