# 휴대폰 리모컨 디자인·가로/세로·프롬프터 — 2026-10-30

가이랩 v0.158.0. 앞선 v0.157.0 기능을 유지하면서 리모컨을 다시 디자인했다. [이전 구현 기록](onbatang-phone-presenter-2026-10-30.md)은 당시의 기록이며 아래 변경이 최신이다.

## 사용 흐름

- **슬라이드**: 현재·다음 그림과 쪽 번호, 발표자 노트를 함께 본다. 그림을 누르면 확대한다.
- **프롬프터**: 그림 대신 현재·다음 쪽의 제목만 간단히 남기고 노트를 크게 읽는다. 자동 스크롤 기능은 아니며 손가락으로 위아래로 읽는다.
- **큰 버튼**: 노트·그림을 숨기고 앞뒤 조작에 집중한다.
- 상단 **자동 배치 / 세로형 / 가로형**에서 배치를 고른다. 자동은 화면 너비·높이에 맞춘다. 폭 600px 미만에서 가로형을 선택하면 세로 배치를 유지하며 옆으로 돌리라는 안내를 표시한다. 기기의 회전 잠금을 해제하거나 강제로 회전시키는 기능은 아니다.
- **가− / 슬라이더 / 가+**로 프롬프터 글씨를 16~48px, 2px 단위로 조절한다(새 기본값 24px). 원래 저장된 18px 등 이전 설정도 보존한다.
- 밝은 미리보기·크림색 노트와 짙은 녹색 하단 조작부로 정보 영역을 구분했다. 가로 화면에서는 슬라이드·노트를 좌우에, 타이머·앞뒤 조작을 아래에 둔다. 짧은 세로 화면의 프롬프터는 보조 문구를 줄여 48px 글자도 한 줄 이상 읽을 공간을 확보한다.
- 조작 설정 버튼에서 쪽 번호 이동, 타이머 1~180분, 초기화, 검은 화면을 사용한다. 모달을 닫으면 원래 버튼으로 포커스가 돌아간다. 일반 연결 확인·수신 성공 메시지는 읽던 노트 위에 번쩍이는 박스로 표시하지 않는다.

## 구현 경계

`dist/onbatang-remote.html`, `onbatang-remote-view.css`, `onbatang-remote-view.js` 변경이다. 공용은 `app/phone-remote.js` → `https://gbe.ai.kr/onbatang-remote-relay.html` → 동일한 리모컨, 가이랩은 직접 연결한다. 공통 편집기 v0.105.0 / 원본 commit `09eb31401389e4da3c935ad552dd110a96404bd5` / 252개 파일은 유지한다. 이번에는 공통 편집기를 변경하거나 내장본을 직접 패치하지 않는다.

설정은 리모컨 코드별 기존 sessionStorage에 최대 8시간 유효하게 유지한다. 같은 탭 새로고침 후 모드·배치·글씨 크기·타이머를 복원한다. 노트·슬라이드 그림·명령은 저장하지 않는다. 화면 모드의 이벤트 대상을 버튼으로 한정해 복원된 body의 data-mode가 클릭 대상에 섞이지 않게 했다. 연결·ACK·교사 잠금·재연결·중복 조작 방지 프로토콜과 SQL은 그대로다.

## 로컬 검증

- 단위 **23/23**: 기존 리모컨·relay 출처 검증·내장본 대조와 함께 배치/회전, 프롬프터/글씨 크기 복원, 손상 설정/이전 설정 호환, 사적인 설정을 발표 명령으로 전송하지 않음, 일반 수신 확인의 박스 숨김을 검증했다.
- 로컬 Headless Edge **3/3**: 가이랩 실제 편집기→발표→리모컨, 공용 standalone→relay→리모컨, 새 디자인 회귀. 임시 BroadcastChannel 사용, localhost/data 외 외부 네트워크 차단. 유료 QA와 실제 계정은 사용하지 않았다.
- 화면: 320×568, 390×844, 667×375, 844×390, 768×1024, 1024×768. 가로 넘침, 하단 버튼 좌표, 48px 프롬프터의 실제 노출 높이(부모/하단 조작부와 교차 영역), 강제 배치/자동 회전, 확대·닫기·포커스, 타이머·설정 새로고침 복원, 교사 잠금·오프라인 복구를 검증했다.
- 작은 화면의 첫 캡처에서 큰 노트 첫 줄이 잘리는 것을 발견해 보조 헤더/문구를 줄이고 재검증했다. 크기 전환 검사는 resize 적용 후 측정한다.
- `npm run build` 통과. 공식 `sync-onbatang ... --check`에서 원본 commit·버전·252개 파일/해시 일치를 확인했다.
- 시각 자료: `work/qa-remote-design-2026-10-30/phone-{320,390,844,768}.png`, `prompter-{320,667,1024}-48.png`, `prompter-portrait-48.png`, `prompter-landscape-48.png`. 직접 만든 픽셀아트 수업 표본이며 개인 수업 PPT/학생 자료가 아니다.
