# 작업 공간과 접이식 슬라이드 목록 · 2026-10-21

공통 온바탕 v0.33.2. 편집기의 아래 목록을 **목록 접기·목록 펼치기**로 조절한다. 접어도 현재 쪽 번호와 이전·다음 슬라이드가 남고, 전체 PPT의 다른 파트로 이동할 때도 기존 저장 보호를 사용한다. 다시 펼치면 접힌 동안 고른 현재 쪽을 목록 안으로 가져온다.

목록 경계 가운데 손잡이를 위아래로 끌면 미리보기 높이를 조절하고 아래로 내리면 접힌다. 손잡이 클릭·Enter·Space는 접기/펼치기, 위/아래 방향키는 높이, Home은 접기, End는 크게 펼치기다. 마우스·터치를 지원하고 포인터 취소나 창 초점 상실은 끌기 전 상태로 돌린다. 미리보기 크기 막대도 유지한다.

- 너비 900px 이상·높이 520~740px의 낮은 편집 창은 저장한 선택이 없으면 처음에 접힌다. 창 크기에 맞춘 기본값이며 크롬북 기종을 추측하지 않는다. 사용자가 고른 뒤에는 접기/펼치기 선택과 미리보기 크기를 이 브라우저의 저장 공간별로 기억한다.
- 넓은 편집 창의 펼친 목록은 최대 화면 높이 42% 또는 320px이고 안쪽을 스크롤해 모든 도구를 쓸 수 있다. 접힌 목록은 한 줄만 남아 캔버스에 높이를 돌려준다. 짧은 화면의 도구 막대는 한 줄에서 좌우로 넘기며 캔버스를 덜 차지한다.
- 목록 UI는 그림·선택한 쪽·쪽 순서·원본 파일·자산·고정 버전·undo 기록을 바꾸거나 서버에 보내지 않는다. 그림 변경과 저장은 기존 편집 경로만 사용한다. 편집기를 닫을 때 포인터 감시를 정리한다.

실제 Edge의 1366×650 전체 PPT 21쪽에서 접기 전후 캔버스 크기, 20번의 접힌 쪽 이동과 파트 경계, 펼쳤을 때 현재 쪽 노출, 손잡이·키보드·새로고침 후 설정 유지와 원본 bytes/쪽 ID 보존을 검사한다. 1024×600·1000×560 창 크기 변경, 390×844의 실제 브라우저 터치 입력·취소도 검사한다. 화면 크기/터치 모의 검증이며 물리 크롬북·모바일 기기 검수와 구분한다.

검증 결과: 공통 전체 단위 **208/208**. 실제 Edge **8개** 고유 검사 통과: 새 목록 3개, 기존 전체 PPT 순서/출력 1개, 1024×768·880×640 터치 PPT 전체 흐름 2개, 문서 저장/재열기와 기존 모서리 크기 조절 2개. 후속 터치 손잡이 재검사는 중복 합산하지 않는다.
