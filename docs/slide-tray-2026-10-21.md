# 얇은 슬라이드 목록과 창 높이 · 2026-10-21

공통 온바탕 **v0.33.3**. 아래 목록은 기본 64px 썸네일 띠와 28px 이동 막대다(데스크톱에서 전체 약 118px). 새 장은 작은 + 단추, 현재 쪽·이전/다음·접기/펼치기는 항상 남는다. 장 복제·삭제·순서 변경·활동/앱·HTML 결과 가져오기는 **··· 슬라이드 도구**에서 연다. 키보드 Escape·바깥 누르기로 메뉴를 닫으며 메뉴 안의 도구 이름을 생략하지 않는다.

경계 가운데 손잡이를 위아래로 끌면 **목록 창 전체 높이(px)**가 바뀐다. 예전 v0.33.2처럼 썸네일 높이만 바꾸는 방식에서 고쳤다. 썸네일은 창 안에 맞추어 표시한다. 아래로 충분히 내리면 접고, 손잡이 클릭·Enter·Space는 접기/펼치기, 위/아래 방향키는 16px 조절, Home은 접기, End는 허용 최대 높이다. 포인터 취소·초점 상실은 끌기 전 상태로 돌린다. 메뉴 안 창 높이 막대는 같은 실제 높이를 조절하고 **창 높이 초기화**는 얇은 기본값으로 돌아간다.

- 접기/펼치기와 높이는 이 기기·브라우저의 저장 공간별 localStorage에 보관한다. 가이랩의 계정별 로컬 저장 공간도 서로 분리한다. 다른 기기로 계정 설정을 동기화하지 않는다.
- 창을 줄이면 캔버스 공간을 남기도록 실제 높이를 제한하되 저장한 높이는 덮어쓰지 않는다. 창을 다시 늘리면 고른 높이를 복원한다. 최소는 마우스 88px/터치 104px이며 상한은 화면 높이 65%와 실제 편집 영역의 남는 공간 중 작은 값이다. 기본 높이를 지정하지 않은 목록은 자연 높이를 사용한다.
- 너비 900px 이상·높이 520~740px의 낮은 창은 기존처럼 저장한 선택이 없으면 처음에 접힌다. 펼친 뒤에는 사용자 선택을 기억한다. 터치 단추는 44px 이상으로 유지한다.
- 설정은 그림·선택한 쪽·쪽 순서·원본·자산·고정 버전·undo를 바꾸거나 서버로 보내지 않는다. 기존 전체 PPT의 다른 파트 이동과 저장 보호를 유지한다.

실제 Edge에서 1366×650의 21쪽 전체 PPT 목록·접힌 20회 이동/파트 경계·다시 펼친 현재 쪽, 1024×600·1000×560, 390×844의 실제 터치 입력/취소를 확인한다. 별도 검사는 197px 설정→37px 끌기→234px→문서 재열기/전체 새로고침, 작은 창에서 임시 제한→큰 창에서 430px 복원, 새 문서와 다른 저장 공간의 분리 및 그림 레코드 불변을 검증한다. 브라우저 화면 크기 모의 검증이며 물리 크롬북 검수와 구분한다.

v0.33.2의 접기/펼치기 기반은 [PR #13](https://github.com/hichoni/onbatang/pull/13)이다. 이번 버전의 정확한 공개 배포 원본·검증 결과는 [최신 인수인계](GAI_ONBATANG_HANDOFF_2026-10-21.md)에 기록한다.
