# 최신 운영본 · 실제 수업 PPT와 PowerPoint 검수

2026-10-19 후속 검수. 공용 Firebase v0.26.4 / `42facf4dd26da21392c40d792a8cc8de62d95c8e`, 가이랩 운영 v0.71.2 / `4407ffc572e16bf2571ebb1935c6a07c769a0647`를 사용했다. 실제 공개 서버의 버전과 핵심 공통 런타임 6파일의 바이트를 확인한 뒤, 새 비영속 브라우저에서 기존 19쪽/11파트 수업 PPT를 내 자료 안에서 가져왔다. 이전 로컬 결과의 재인용이 아니라 이번 공개 런타임에서 다시 실행한 결과다. [통합 증거](qa/2026-10-19-latest-public-native-review.json).

공용·가이랩 각각 브라우저 16항목을 통과했다. 19쪽 전체 이동 중 편집기·목록 DOM이 유지됐고 위치/높이 변화는 0px였다. 빠른 19쪽 이동에 로딩 안내가 추가되지 않았다. 포인터 드래그와 Alt+←로 쪽 순서를 바꾸고 되돌린 뒤, 파트 경계에서 원본 19·18쪽의 순서를 바꿔 저장했다. 새로고침 후 전체 순서와 첫/마지막 파트의 편집 초안 제목이 유지됐다. 팔레트 1~4 각각에 서로 다른 이름과 색을 저장하고 새로고침 뒤 네 슬롯 모두 확인했다. 색을 시험한 슬라이드의 배경색은 원래 색으로 돌렸다.

두 서비스에서 편집형·이미지형 PPTX ‘모든 장’을 내려받았다. 네 파일 모두 순서 변경된 19쪽과 원래 16:9 크기(12192000 × 6858000 EMU)를 유지했다. 원본 파일 SHA-256, 이전 전체 자료 고정본, 처음 내려받은 네 사본도 동일 바이트로 보존됐다. 실제 수업 원본·출력·스크린샷은 Git에서 제외한 로컬 work/ 안에만 보관한다.

PowerPoint를 실제 Windows UI로 조작해 네 파일을 각각 열었다. 편집형 공용 사본은 첫 장의 쪽 표기를 105→106으로 바꾸고 영문 글꼴 Arial 28pt 및 원형 도형 위치를 수정했다. 가이랩 편집형도 쪽 표기 105→107과 도형 위치를 수정했다. 두 이미지형은 첫 장 그림을 모서리에서 줄였다. 각각 **다른 이름으로 저장 → 닫힘 확인 → 저장한 파일 재열기**를 수행했고 네 저장본 모두 전체 19개 축소판이 그려졌다. 복구 경고는 관찰되지 않았다.

저장된 OOXML을 다시 읽어 편집형의 바뀐 글자와 도형 좌표, 공용의 Arial 28pt를 확인했다. 다른 18쪽의 텍스트는 유지됐다. 이미지형은 첫 그림의 크기 변화, 나머지 18쪽 좌표 보존(2 EMU 이내 반올림), 전체 19개 그림 바이트 보존을 확인했다. 이미지형에서는 글자를 개별 편집할 수 없으며 그림 전체를 편집한다. 전체 쪽의 원본 대비 픽셀 단위 대조나 다른 기기의 글꼴 설치 상태를 검증한 것은 아니다.

이번 요청의 브라우저·PowerPoint 검수는 완료했으며 제품 코드나 배포는 변경하지 않았다. 유료 QA 환경·실제 계정·메일·운영 DB를 사용하지 않았고 원격 쓰기와 외부 요청은 각각 0회였다. 원본과 기존 PR·미완료 변경을 보존했다. 실제 계정/새 기기 계정 복구, 물리 기기/35명, 화면 스포이드 직접 추출은 별도 미실행이다. 다음 작업은 이 범위를 추가로 요청받을 때 해당 환경에서 진행한다.
