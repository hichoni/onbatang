## 이번 기능

### 작업 여백에서 드래그 선택

공통 `createEditor().setSelectionSurface(element)`에 호스트의 `.cv-canvas`를 연결했다. 종이 바깥의 빈 배경에서 왼쪽 마우스로 시작해 종이 안으로 들어가거나 반대 방향으로 가도 같은 선택 사각형을 사용한다. Shift는 기존 선택에 더하고 잠긴 요소는 제외한다. 버튼·입력 칸·터치 스크롤은 가로채지 않는다. 편집기 폐기/다른 surface 연결 때 listener를 정리한다.

### 행사와 연수의 기본 틀 30종

기존 24종에 행사·무대, 연수·워크숍, 학교·공동체, 회의·포럼, 안내·캠페인 각 6종을 더해 **54종**이다. 표지뿐 아니라 식순·강사 소개·연수 목표·실습·돌아보기·시상·학부모 설명회·전시·할 일 표·안내·준비물 등 짜임이 다르다. 외부 디자인 파일을 복제하지 않고 편집 가능한 글·도형으로 만들었다.

첫 화면 **행사·연수**에서 바로 시작하거나 편집기의 **틀 찾기 / 틀 분류**를 사용한다. 원본 비율과 기본 비율을 지원한다. 세부 목록·참고 자료: [틀 문서](occasion-layouts-2026-10-29.md).

### 연속형 움직임 묶음 6종

움직임 칸의 **이야기가 이어지는 움직임 묶음**에서 이야기 지도·생각의 궤도·한 줄의 여정·관찰의 렌즈·주인공의 무대·숨 쉬는 연결을 고른다. 실제 5장 미리보기, 요소 빠르기, 숨쉬기, 차분하게, 새 예제의 세 주제 순서가 있다.

- 기존 자료 적용은 글·사진·배치·ID·출처·앱 데이터를 유지하고 모션만 바꾼다. **여러 파트 PPT는 현재 편집 중인 파트에 적용**한다고 화면에 명시한다. 파트 전체를 일괄 바꾸는 기능으로 오해하지 않는다.
- **5장 예제로 새 그림**은 현재 자료를 먼저 저장하고 별도 새 그림을 만든다. 전체지도 → 주제1 → 주제2 → 주제3 → 요약 사이에서 원본 요소 ID를 따라 이어 움직인다. 각 장/요소 ID는 새로 만들며 공유 원본 식별자로 짝지어 저장·재열기 후에도 연속성이 남는다.
- 요소 숨쉬기·이어 움직이기는 기존 공통 발표/HTML/영상 런타임을 사용한다. 시스템의 움직임 줄이기에서는 정적으로 보인다. 빠르기 옵션은 요소 동작에 적용하며 이어 움직이기 전환은 기존 1초다.

[API와 검증](motion-sets-2026-10-29.md). AI 생성 요청이나 외부 이미지/글꼴 다운로드는 없다.

### 수업용 리모컨

공통 발표는 리모컨을 열 때만 현재·다음 두 장을 320px JPEG로 만들고 작은 미리보기만 기존 리모컨 채널로 전달한다. 검은 화면과 활동 여부도 동기화한다. 원본 PPT·앱 코드·세션 토큰·자산 URL은 전달하지 않는다.

가이랩 리모컨은 현재/다음 그림·메모, 큰 버튼 모드, 쪽 번호 이동, 1/3/5분 활동 타이머, 연결 상태, 명령 수신 확인, 발표자의 잠금과 링크 복사를 제공한다. 오프라인에서는 조작을 보내지 않고 ACK가 없어도 자동으로 같은 넘기기를 다시 보내지 않는다. 기존 허용 명령과 Supabase broadcast를 사용하므로 SQL/DB 추가 변경이 없다. 공용은 기존의 가이랩 relay를 통해 같은 리모컨을 쓴다.

- 운영 DB·SQL·RLS·계정·저장소 구성 변경 **0**, 유료 QA **0**, 추가 AI 호출 **0**. 원본 자료를 검수용 fixture로 덮어쓰지 않는다.
