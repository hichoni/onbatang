# 슬라이드와 픽셀아트가 함께 실행되는 수업 · 2026-10-19

공통 온바탕 v0.27.0. 기존 PPT와 고정 revision을 보존하며 유료 QA·계정·운영 DB를 사용하지 않는다.

## 교사 흐름

1. 내 자료 → PPT에서 수업 PPT를 가져온다.
2. 활동을 넣을 앞쪽 슬라이드를 선택하고 아래 `+ 활동 추가`를 누른다. 제목·안내·8/12/16칸·색상을 정한다.
3. 발표에서 해당 쪽에 도착하면 같은 화면 안에서 픽셀아트를 실행한다. 외부 링크·새 탭으로 이동하지 않으며 짧은 확대 전환을 사용한다. 동작 줄이기 설정을 존중한다.
4. `결과를 다음 슬라이드에 저장`을 누르면 그림을 일반 이미지 요소로 담은 다음 쪽을 생성하고 이동한다. 전체 자료의 새 고정본과 쪽 순서에 함께 기록한다. 같은 발표에서 같은 그림을 다시 저장하면 이미 만든 결과를 연다.
5. 내려받기 → `HTML 수업`은 모든 파트의 슬라이드·활동을 단일 오프라인 HTML로 만든다. HTML 안에서도 활동 실행·다음 쪽 결과 저장·현재 수업 재다운로드가 가능하다.

## 데이터·실행 계약

- 페이지의 선택 필드 `activity` v1: `kind:'pixel-art'`, 고유 `id`, `title`, `instructions`, `size`(8/12/16), `palette`(2~12 HEX), `cells`(size², -1 또는 팔레트 인덱스). 정리·복제·저장·재열기에 검증한다. 복제는 새 활동 ID를 부여한다.
- 활동 표지·결과는 일반 편집 요소도 함께 갖는다. PPTX에서는 정적인 표지/결과로 출력하며 앱 실행은 온바탕 발표나 HTML에서 제공한다.
- 전체 자료는 기존 파트를 유지하고 쪽 ID 기반 순서로 표시한다. 활동을 추가할 때 첫 결과를 위한 공간을 확보한다. 모든 파트가 20쪽/용량 한도에 도달하면 원본을 보존한 채 명시적으로 안내하며 몰래 쪽을 버리거나 새 파트를 만들지 않는다.
- `materialNavigation.saveActivity({designId,materialRef,document,pageOrder,expectedDocument})`는 자료 고정본과 순서를 원자적으로 저장한다. 현재 대상 파트만 승격하고 다른 파트의 초안을 고정본에 섞지 않는다.
- 고정본을 기록한 뒤 로컬 초안을 CAS로 갱신한다. 충돌/저장 공간 문제는 `recoveryRequired:true`와 경고로 반환한다. 편집기는 추가 자동 저장을 차단하고 활동 저장 또는 발표 종료 뒤 내 그림으로 돌아간다. 다른 창 초안을 덮지 않으며 고정 저장 성공을 실패로 오인하지 않는다.
- 전체 목록 읽기 실패 시 전체 발표/HTML 내보내기를 부분 성공으로 표시하지 않는다.
- HTML의 일반 슬라이드는 그림, 픽셀아트는 실행 가능한 데이터와 코드다. 외부 네트워크 요청 없이 동작하며 동영상·애니메이션은 정지 화면이다. localStorage가 제한되어도 메모리 작업과 재다운로드를 유지한다. 최대 500쪽과 이미지 용량 한도를 검사한다.
- HTML에서 만든 결과는 해당 HTML에 저장한다. 원래 온바탕 자료에 자동 역동기화하지 않는다. 임의 HTML 앱·가이X 생성 앱·학생 계정 제출 수집은 이번 구현에 포함하지 않는다.

## 검증

- 공통 단위 189개 통과. 픽셀 데이터·정리/복제·HTML 삽입 문자열 처리·기존 PPT 변환/출력 회귀 포함.
- 자체 제작 21쪽 → 활동·결과 포함 23쪽. 실제 수업 PPT 19쪽 → 10쪽 다음 활동, 바로 다음 결과, 총 21쪽. 원본 파일 SHA-256 `c165d32bda450cec385e5bc916351c75d72b6acc69abdea5931d2d473f10d12d` 보존.
- 실제 worker 가져오기, 색칠/undo/키보드 격리, 전체 자료 순서, 중복 결과 재사용, 고정 원본 보존, 두 차례 재열기, 편집형·이미지형 PPTX 쪽 수와 결과 검증.
- HTML 전체 수업 출력 → 외부 네트워크 차단 상태 앱 실행 → 추가 결과 → 재다운로드 → 새 브라우저 모바일 크기에서 재열기 검증.
- 초안 CAS는 실제 두 브라우저 탭 동시 갱신, 같은 revision의 다른 내용, 단조 증가 revision, 저장 실패 재시도 검증.

실제 기기·PowerPoint 직접 실행·계정 QA·35명 동시 참여는 이번에 실행하지 않았다. 로컬 브라우저 검증과 공개 배포 확인은 별도 기록한다. 원본 PPT와 검수 출력은 무시되는 로컬 work 폴더에만 보관한다.

다음 작업: 활동 목록·다른 내장 앱, HTML 결과를 온바탕으로 명시적으로 다시 가져오기, 가이X 제작 앱의 실행·상태·결과 계약과 격리 검증. 계정/학생 수업방 연결은 별도 승인된 DB 범위에서 진행한다.
