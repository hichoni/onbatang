# 온바탕 디자인·모핑 재설계 인수인계 — 2026-10-30

## 사용자 피드백과 작업 범위

공용 v0.104.0을 직접 사용한 사용자는 모핑이 매끄럽지 않고, 카드/HTML 위젯처럼 보이며, 기본 틀의 시각적 완성도가 부족하다고 지적했다. 이를 단순 효과/개수 추가로 처리하지 않고 내부 디자인 리뷰와 템플릿·공간 모션 구현 역할을 나눠 재설계했다. 외부 디자이너를 실제 고용한 것은 아니다.

공통 후속은 **v0.105.0**, 가이랩은 앞선 기능·리모컨 PR #214를 보존하며 **v0.156.0**으로 통합한다. 이전 [10월29일 작업](GAI_ONBATANG_HANDOFF_2026-10-29.md)의 여백 선택·리모컨·원본 보존도 유지한다.

## 실제 변경

### 모핑이 끊기는 원인 수정

`playIdle()`은 `delay - phase`를 쓰고 있었다. 새 장의 phase가 전환 지연보다 크면 음수 지연이 되어 숨쉬기 애니메이션이 카메라 전환보다 먼저 시작하고 같은 `transform`을 덮었다. 이제 실제 지연을 보존하고 `iterationStart`로 반복의 위상을 분리한다. 전환 뒤 시작하는 반복은 제자리 위상에서 출발한다.

나가는 장의 반복을 취소해 중립 자세로 되돌린 뒤 측정하던 것도 수정했다. `playDesign.stop({freeze:true})`는 보이던 변환·불투명도·필터를 유지하며, `morphFrames`는 표시 중인 2D 행렬을 사용해 그 크기/각도에서 다음 모습으로 잇는다. 일반 `stop()`·편집기 `restore()`는 기존 정리 동작을 유지한다. 공통 발표와 작은 재생기 양쪽에 적용했다.

검증은 단순 Animation 유무 대신 실제 합성된 0·25·50·75·99·100% 중간 프레임의 위치/크기 단조 변화와 출발/도착 순간의 튐을 비교한다. 이미 저장한 v104 예제도 런타임 오류 수정은 받지만, 그 자료의 디자인을 자동 재작성하지는 않는다.

### 한 공간을 탐색하는 6개 이야기

- 이야기 지도: 아이보리·먹색·주황, 지형선과 항로.
- 생각의 궤도: 미드나이트·라일락·라임, 천체와 궤도.
- 한 줄의 여정: 흑백·코발트, 긴 트랙과 큰 단계 숫자.
- 관찰의 렌즈: 관찰창과 잎의 구조를 가까이 살피기.
- 주인공의 무대: 블랙·크림·골드, 조명과 발화자.
- 숨 쉬는 연결: 따뜻한 백색·청록·구리, 유기적 도형과 가는 연결선.

각 세트의 공유 요소에는 **하나의 동일한 카메라 affine 변환**을 적용한다. 장마다 카드의 위치를 임의 재배열하거나 같은 요소의 글을 주제명→숫자로 바꾸지 않는다. 제목/설명은 별도 요소이며 카메라 착지 후 나타난다. 반복은 작은 장식 최대2개에 한정한다.

카메라 밖의 요소를 삭제하거나 종이 끝에 몰지 않도록 `layout:'slide'`의 x/y를 **-500~500** 내에서 보존한다(기존 정밀도 유지). 일반 편집 요소는 기존 0~100 범위를 유지한다. 새 SQL/테이블/스키마 버전 변경은 없으며, 소스와 원본 내용은 그대로 남긴다.

움직임 선택 창은 큰 무대·스타일 목록·5장 필름스트립·재생/앞뒤 조작으로 재구성했다. 데스크톱에서는 저장/새 예제 버튼을 미리보기와 같은 화면 안에 두고, 모바일은 세로 흐름으로 사용한다. 선택과 주제 입력은 저장 실패 후에도 남는다.

### 30종 재디자인 + 4개의 5장 디자인 세트

행사·연수 30종을 같은 팔레트/카드 반복에서 개별 구도·타이포·그래픽으로 다시 만들었다. 시상식 장식 과잉, 표지 footer 대비, 웃는 기본 아바타, 연도 중복 등 실제 시각 리뷰의 지적을 수정했다. 외부 디자인을 복제하거나 새 이미지·글꼴을 다운로드하지 않았다.

첫 화면 **디자인 세트**의 현장 노트·배움 신호·함께 자란 시간·다음 학교는 표지→차례→내용/실습→비교/기록→마무리가 같은 스타일로 이어지는 5장을 한 번에 저장해 연다. 모든 글과 도형은 개별 편집 가능하다. 20개 세트 레이아웃을 더해 전체 틀은 **74종**이다. 기존 그림을 덮어쓰지 않고 새 문서와 새 요소 ID를 만든다.

디자인 방향 참고: [Apple Magic Move](https://support.apple.com/en-mo/guide/apple-vision-pro/tan72234bb6/visionos)의 공통 대상 연속성, [Prezi visual story](https://support.prezi.com/hc/en-us/articles/19040250379287-How-to-turn-text-into-a-visual-story-with-Prezi-AI)의 공간적 이야기 구성, [Pitch 템플릿](https://pitch.com/templates/)의 일관된 페이지 패밀리를 참고했다. 경쟁 제품보다 품질이 우수하다는 검증이나 주장은 하지 않는다.
