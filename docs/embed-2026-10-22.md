# 들여쓰기(다른 앱에서 온바탕 불러 쓰기) · v0.56.0

명세 "온바탕 들여쓰기 · 선생님 기능 명세(초안, 2026-10-22)"의 1단계. 받은함 · 선생님 갤러리 · 고쳐 주기(2~4단계)는 서버가 필요해서 공용 온바탕에 넣지 않는다(아래 "다음 단계").

## 부르는 쪽

```html
<script src="https://onbatang.web.app/app/embed.js"></script>
<script>
  const result = await Onbatang.open({
    ratio: '9:16',            // 1:1 · 4:5 · 16:9 · 9:16(기본)
    template: 'band',         // (선택) 시작 틀: cover · band · list · bubble · question · end · 주제 테마(tnet …)
    record: null,             // (선택) 다시 고칠 원본(예전에 받은 result.record)
    title: '우리 앱 화면',     // 그림 이름(30자까지)
    tools: 'simple',          // 'simple'(기본) | 'full'
    png: { width: 1080 },     // 돌려받을 그림 너비(64~4096)
    container: null,          // (선택) 이 요소 안에 띄운다. 없으면 화면 위 전체
  });
  // 닫기 → null, 다 했어요 → { png: Blob(image/png, 첫 장), record }
</script>
```

- `embed.js` 는 모듈이 아닌 보통 스크립트이고, 자기 주소 옆의 `embed.html` 을 iframe(`allow="fullscreen"`)으로 띄운다. 한 번에 하나만 연다(열려 있으면 거절).
- 결과의 `record` 는 온바탕 그림 기록 그대로다(사진은 data 주소). 부른 앱이 질문 · 제출과 함께 저장하고, 다시 고칠 때 `record` 로 넘긴다.

## 신호(postMessage)

| 방향 | 신호 | 내용 |
|---|---|---|
| 온바탕 → 부른 쪽 | `onba:ready` | 준비됨(내용 없음, 대상 `*`) |
| 부른 쪽 → 온바탕 | `onba:init` | 위의 설정 |
| 온바탕 → 부른 쪽 | `onba:save` | `{ record, png }`(Blob 그대로) |
| 온바탕 → 부른 쪽 | `onba:close` | 저장 없이 닫음 |
| 온바탕 → 부른 쪽 | `onba:error` | 열지 못함 `{ message }` |

- `embed.js`: 그 iframe(`event.source`)과 온바탕 주소(`event.origin`)의 신호만 받는다.
- `embed-host.js`: 부모 창의 `onba:init` 만, 그것도 처음 하나만 받고, 그 주소에만 결과를 보낸다. `EMBED_ALLOW`(비우면 어디서나)로 부를 수 있는 주소를 좁힐 수 있다. 설정은 `cleanInit` 이 정리하고, 원본은 `migrateRecord` 로 거른다(모르는 값은 버린다).

## 들여쓰기 모드(`app/embed.html` · `app/embed-host.js` · `startMinican({ embed })`)

- `startMinican` 의 `embed: { done(id), close(id) }` 를 주면 꾸미는 화면 위 막대가 닫기 · 이름 · 저장 상태 · ? · 다 했어요가 된다(첫 화면 단추 · 모양 바꾸기 · 발표 · 내려받기 · 자료 단추 없음). 바탕 영상(`saveVideo`) · 카메라는 끄고, 사용법 안내는 보여 주지 않는다(? 단추로 본다).
- `tools: 'simple'` 은 `configure({ motion: false })` 로 움직임 칸을 숨긴다.
- 저장소: `embed-<부른 주소 SHA-256 앞 6바이트>`(이 기기의 IndexedDB). 열 그림 = 넘겨받은 원본 > 남은 초안 > 새 그림(비율 · 이름 · 시작 틀). 다 했어요 = `flushSavedDesign` → `designToBlob(첫 장)` → `onba:save` → 초안 지움. 닫기 = 저장만 마치고 `onba:close`(초안은 남는다).
- 꾸미는 화면이 열릴 때까지 여는 화면으로 덮는다(첫 화면이 비치지 않게). 혼자 열리면 쓰는 법을 알린다.

## 다음 단계(명세 2~4: 받은함 · 갤러리 · 고쳐 주기)

- 서버는 명세의 추천(풍풍 큐 랩 Firebase) 대신 **가이랩 Supabase** 가 낫다: 선생님 · 학생 계정(0.95.1), 온바탕 그림 표(`gailab_minican_designs`) · 사진 보관함(`minican-files`), 수업방(`gailab_onbatang_rooms` · members · submissions · saves)이 이미 있다. 받은함은 수업방의 "자유 그리기" 한 가지로 얹을 수 있다.
- 편집기 쪽에 필요한 것: 선생님 모드에서 새 요소의 이름표를 `tch…` 로 붙이는 `createEditor({ newItemId })`, 읽기 전용 · "잠깐! 선생님을 봐요", 선생님 펜 보기/숨기기. 들여쓰기 모드의 `embed` 연결(`done` · `close`)에 받은함의 sync 를 끼우면 된다.
- 가이랩의 Supabase 자동 배포(`.github/workflows/supabase-deploy.yml`)가 2026-10-20 부터 실패 중(실행 기록 없음)이라, 새 SQL 은 지금 손으로 적용해야 한다.
