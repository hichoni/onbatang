# 새 리모컨 · 실제 수업 PPT 검수와 터치 개선 — 2026-10-30

## 이번 범위

v0.159.0의 새 리모컨을 실제 실과 6학년 6단원 3차시 PPT로 검수했다. 공용과 가이랩 각각 새 로컬 사본을 사용했다. 기존 운영 Realtime/실제 계정 검수와 이번 화면 크기별 검수를 구분한다. 유료 QA는 사용하지 않는다.

## 수정 — v0.159.1

- 화면 모드, 글씨 크기 버튼/슬라이더, 타이머, 설정의 자주 쓰는 터치 영역을 44px 이상으로 키웠다. 가로 화면에서 글씨 크기 버튼이 32px로 줄어들던 규칙도 보완했다.
- 타이머 이름과 숫자를 위아래로 배치하고 버튼 글을 한 줄로 유지한다. 180:00과 시간이 끝난 뒤의 ‘다시 시작’이 들어가도 조작부가 밀리지 않게 했다.
- 짧은 가로 화면은 모드 선택 주변 여백을 줄여 48px 프롬프터의 한 줄 이상과 고정 하단 버튼이 함께 보이게 했다.
- CSS만 수정했다. QR/실시간 전송/명령/저장 계약과 공통 편집기는 그대로다. 공용 relay와 가이랩 직접 연결이 같은 리모컨 화면을 사용한다.

## 실제 자료와 검증 구분

원본은 19쪽, 19,627,567바이트이며 SHA-256은 `c165d32bda450cec385e5bc916351c75d72b6acc69abdea5931d2d473f10d12d`다. 다운로드 폴더의 원본은 읽기만 하고, Git에서 제외한 `work/` 사본을 실제 가져오기 UI에 넣었다. 19쪽을 11파트로 저장하며 원본에서 숨긴 2쪽은 편집 자료에 남고 발표에서는 제외된다. 따라서 리모컨 발표 순번은 18쪽이다.

검수 사본의 첫·마지막 장에만 발표자 노트를 추가했다. 홈으로 나가 새로고침한 뒤 전체 자료를 다시 열어 노트와 리모컨 재연결을 확인한다. 고정 자료 그래프와 원본 자산은 변경하지 않는다.

공용은 standalone→phone-remote→relay, 가이랩은 내장 편집기→직접 리모컨 경로다. 실시간 전송은 로컬 BroadcastChannel, 계정 연결은 fixture이며 외부 HTTP/WebSocket은 차단했다. 이번 실제 PPT 실행을 운영 계정·운영 Realtime·실제 휴대폰 검증으로 표시하지 않는다.

## 실제 휴대폰에서 남은 확인

사용자는 앞선 운영 리모컨이 실제 휴대폰에서 정상 작동했다고 확인했다. **이번 v0.159.1의 터치 영역·회전·새 레이아웃은 실제 휴대폰 재검수 전**이다. 자동 화면 크기 변경은 센서 회전이나 손가락 조작을 대신하지 않는다.

1. PC에서 수업 자료를 열고 **발표 → 리모컨 QR**을 표시한다. 휴대폰으로 QR을 찍어 현재·다음 장이 맞는지 본다.
2. 휴대폰 회전 잠금을 해제하고 세로→가로→세로로 돌린다. 노트와 타이머·앞뒤 버튼이 잘리지 않고 누르기 편한지 본다. 수동 배치는 오른쪽 위 **조작 설정 → 화면 배치**에서 고른다.
3. **프롬프터**에서 가−/가+와 슬라이더로 글씨를 조절하고 48px에서 노트를 위아래로 민다. 회전 후에도 선택한 크기와 읽던 위치가 유지되는지 본다.
4. **조작 설정 → 활동 시간 → 직접 설정**에서 시간을 정한 뒤 시작·멈춤·계속·+1분을 눌러 본다. 화면을 잠갔다 다시 켰을 때 타이머와 슬라이드 버튼이 복구되는지 확인한다.

iOS Safari, 실제 QR 카메라, 회전 잠금, 주소창 높이 변화, 손가락 터치, 화면 잠금/복귀, Wi-Fi↔모바일 데이터 전환은 별도 미완료다. 별도 유료 QA 프로젝트를 만들 필요는 없다.
