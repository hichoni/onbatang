# 키노트·프레지에서 배운 것 · v0.37.0 (2026-10-21)

v0.36.0 뒤에 애플 키노트와 프레지를 견줘 보고(공식 도움말 기준. 이 작업 환경은 두 사이트에 직접 들어가지 못했다), 온바탕에 이미 있는 것(움직임 · 전체 보기 · 카메라) 위에 얹을 수 있는 세 가지를 골라 만들었다.

| 배운 것 | 키노트 · 프레지 | 온바탕 v0.37 |
| --- | --- | --- |
| 같은 요소가 장 사이에서 움직이기 | 키노트 매직 무브, 파워포인트 모핑 | **이어 움직이기** 전환 |
| 전체 그림 → 주제로 확대 | 프레지의 주제(topic)·개요와 확대 이동 | **주제(구역)** + 전체 보기를 주제로 묶고 확대해 들어가기 |
| 발표자 얼굴을 슬라이드 위에 | 키노트 라이브 비디오, 프레지 비디오 | **카메라 창**(C) |

## 이어 움직이기

- 전환 효과 id `move`(`src/motion.js`). 짝짓기는 DOM 을 모르는 `matchItems(앞 장 요소, 이 장 요소)`:
  1. 종류가 같고 이름표가 같거나, 한쪽이 다른 쪽을 복제했거나(`copySlide` 가 남기는 `origin.elementId`), 같은 원본에서 복제한 것.
  2. 남은 것 중 종류와 내용(글 · 그림 주소 · 스티커 · 도형 모양과 색 · 그림 묶음 · 유튜브)이 같은 것이 양쪽에 하나씩만 있을 때.
- 재생(`playMorph`): 짝이 된 요소는 앞 장에서 잰 자리·크기·글자 크기·각도(transform)·투명도·색에서 이 장의 값으로 Web Animations 로 옮겨 간다. 앞 장의 짝은 바로 감추고, 짝 없는 앞 장 요소는 사라지고, 이 장에만 있는 요소는 조금 늦게 나타난다. 바탕은 따로 깐 판(`.fe-morph-back`)으로 서서히 바뀐다. 끝나면 흔적 없이 걷는다(다른 전환과 같다).
- 옮겨 온 요소에는 `data-moved` 를 달아 `playDesign` 이 다시 "나타나기" 효과를 틀지 않는다. 누를 때 나오는 조각은 그대로 기다린다.
- 발표 화면만 두 장의 디자인을 함께 안다(카드 → 디자인 `WeakMap`). 앞 장으로 돌아갈 때는 거꾸로 옮겨 간다. 편집 화면 미리 보기와 영상 만들기는 한 장만 알아서 **서서히 바뀌기**로 대신한다(`transitionPose('move')` 의 frames). 움직임을 줄인 기기에서는 다른 전환처럼 틀지 않는다.
- PPTX 는 지금처럼 전환·움직임을 담지 않는다(정지 모습 + 안내).

## 주제와 확대 보기

- 장의 `topic`(한 줄 40자, `cleanTopic`·`slideTopic`): 이 장부터 다음 주제 앞까지가 한 주제. 장 메뉴 `여기서 주제 시작` / `주제 이름 고치기`(비우거나 `주제 없애기`로 없앤다). 슬라이드 목록의 작은 그림 아래에 주제 이름이 붙는다.
- 전체 보기(G, `app/show-tools.js`): 주제가 하나라도 있으면 `topicGroups` 로 묶어 주제 이름(첫 쪽–끝 쪽) 아래에 작은 그림을 놓는다. 첫 주제 앞의 장은 「처음」. 열 때 지금 쪽 그림이 발표 화면만 한 크기에서 제자리로 줄어들고(멀리서 보기), 주제 이름이나 그림을 누르면 그 그림이 발표 화면만큼 커진 뒤 그 쪽으로 간다(0.42초, 움직임을 줄인 기기는 바로). 열리는 중에 눌러도 바로 들어간다.
- 숨긴 장에서 시작한 주제는 그다음 보이는 장으로 넘긴다(`shownTopics`). 발표 · HTML 수업이 같은 규칙을 쓴다. 발표자 화면에는 `주제: …` 가 보인다.
- PPTX: 편집형 내보내기는 `p:presentation/p:extLst` 에 PowerPoint 2010 구역(`p14:sectionLst`)을 쓴다. 구역은 모든 장을 덮어야 해서 첫 주제 앞 장은 「처음」 구역이 된다. 가져오기는 구역마다 첫 장에 구역 이름을 주제로 붙인다(그래서 「처음」 구역도 주제가 된다).

## 카메라 창

- 발표 도구에 `카메라` 단추와 C 글쇠(`show-keys.js`). `getUserMedia({ video, audio: false })` — 마이크는 켜지 않는다. 녹화·전송·저장은 없다(화면에만 보인다).
- 동그란 창이 오른쪽 아래에서 시작. 끌어서 옮기고(발표가 넘어가지 않는다), 두 번 누르면 크게(34%)·작게(20%). 거울처럼 좌우를 뒤집어 보여 준다. 검은·흰 화면은 카메라 창까지 덮는다. 발표자 화면 창에는 나오지 않는다.
- 다시 C, 발표 끝내기, 발표 화면 닫기에서 카메라 트랙을 멈춘다. 카메라 허락을 묻는 동안 브라우저가 전체 화면을 풀어도 발표는 끝나지 않는다(발표자 화면과 같은 규칙, F 로 다시 켠다).
- 온바탕 발표와 HTML 수업이 같은 `createShowTools` 를 쓰므로 둘 다 된다. 막혔거나 카메라가 없으면 안내만 띄운다.
