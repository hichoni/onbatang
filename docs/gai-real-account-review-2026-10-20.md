# 실제 계정 가이X 앱 검수 · 2026-10-20

## 범위와 결과

실제 가이랩 교사 계정으로 가이X에 요청해 실과 6학년 3차시 PPT에 맞는 앱을 생성·수정했다. 결정적인 가짜 응답을 사용하는 로컬 테스트와 구분한다. 공용 Firebase와 가이랩 Netlify 운영 화면에서 각각 원본 16쪽 다음에 앱 17쪽, 결과 18쪽을 저장하고, 전체 21쪽을 다시 열어 확인했다. 원본 19쪽의 순서와 페이지 ID를 유지하며 파트 11개를 하나의 자료로 다룬다.

공용은 실제 계정 연결 창을 거쳐 생성했다. 가이랩은 직접 편집 경로에서도 조작한 후 실제 서비스의 로그인 화면 안에서 동일 저장본을 재열어 확인했다. PPT·앱·결과는 **이 브라우저의 기기 저장**이다. 실제 계정 로그인·AI 이용을 확인한 것이며, PPT의 새 기기 계정 복구를 완료했다고 해석하지 않는다.

## 실제 발견한 문제와 수정

PPT의 다른 파트를 방문하면 편집기에서 정규화한 화면 사본을 해당 파트의 저장 기준으로 사용했다. 큰 파트에서 앱을 넣어 앞서 방문한 다른 파트에 저장할 때 실제 초안과 달라져 거짓 충돌을 안내했다. `app/app.js`가 마지막 저장에 성공한 `persistedRecord`를 기준으로 보관하도록 수정했다. 외부 창의 실제 편집 충돌 보호는 유지한다.

자체 21쪽·20+1 파트 회귀 검사는 수정 전 같은 충돌로 실패하고 수정 후 통과했다. 실제 공용 PPT에서도 1쪽→16쪽으로 이동한 뒤 생성 초안을 복구해 앱을 삽입하는 흐름을 통과했다. iframe의 테두리는 같은 모양의 그림자로 바꿨으며 sandbox·CSP·권한은 완화하지 않았다.

가이랩에서 다른 검수 창이 만들었던 초안을 새 창에서 수정할 때에는 별도의 실제 기준 revision 보호가 동작했다. ‘전체 자료에 저장’ 비교 화면에서 현재 파트 초안을 명시적으로 채택하고 다른 파트는 현재 고정본으로 유지한 뒤, 보관된 AI 수정 후보를 추가 요청 없이 반영했다. 이전 고정본은 남는다.

## 한계·미완료·다음 작업

1. 유료 QA 프로젝트는 사용하지 않았다. **기존 가이랩 AI 이용량은 사용했다.** 공용 첫 생성 1회는 시간 초과, 축약 요청과 후속 수정으로 복구했다. 총 실제 요청 7회 중 6회 완료·1회 시간 초과이며, 과금·이용량 환급 여부는 확인하지 않았다. 추가 가이랩 키보드 수정은 자동 승인 검토에서 한 번 거절된 후 사용자의 명시적 1회 허용을 받아 실행했다. 거절 자체는 전송 요청 수에 넣지 않는다.
2. 검수 도구가 중첩 sandbox의 마우스 좌표를 전달하지 못했다. 입력은 정상 키보드 동작으로 검증했다. 사용자는 직접 조작 검수를 미완료로 남기도록 선택했다. 실물 마우스·터치·휴대폰·태블릿·35명 수업 검수는 미완료다. 이 제한을 제품의 마우스 동작 실패로 단정하지 않는다.
3. 가이랩 HTML은 완료 안내까지 확인했으나 브라우저 다운로드 이벤트와 로컬 수신 파일을 확정하지 못했다. 실제 가이랩 HTML 파일 수신 검수는 미완료다. 공용 파일 검증을 가이랩 파일 수신 성공으로 대신하지 않는다.
4. 가이랩 ‘전체 자료에 저장’ 비교 화면은 파트 저장 순서로 미리보기를 나열해, 앱·결과를 중간에 넣은 전체 자료 순서와 다른 위치·중복 원본 번호를 표시하는 문제가 발견됐다. 편집기 레일·발표·고정된 pageOrder·재열기 순서는 정상이다. 다음 UI 수정에서는 이 비교 화면도 pageOrder로 정렬하고, 추가 앱·결과에 원본 쪽 번호를 붙이지 않아야 한다.
5. PPT 계정 백업·새 기기 복구·다른 계정 접근 제어·학생 참여·제출·서버 채점은 이번 운영 범위에 포함하지 않았다. 운영 DB를 보존하며 기존 기능 PR #76과 구분한다.
