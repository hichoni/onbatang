# 온바탕 인수인계 · 리모컨 구절과 교사 메모

2026-11-04 · 공용 0.125.0 · 가이랩 0.179.0

## 사용법

글 조각의 **시네마 효과 / 효과 수정 → 화면 · 타임라인 편집**을 연다. 화면이나 타임라인에서 구절을 선택하고 **이 구절의 교사 메모**를 작성한다. **발표 방식 → 클릭·리모컨으로 하나씩 공개**로 설정해 슬라이드에 적용한다. **움직임 저장**으로 이름 붙이면 메모도 프리셋에 저장되어 다른 자료에서 다시 쓸 수 있다.

발표의 **휴대폰 리모컨**을 연결하면 아직 첫 구절을 열기 전부터 다음 구절과 메모가 보인다. 공개할 때마다 현재 구절·다음 구절과 각각의 교사 메모가 바뀐다. 빈 메모는 칸을 만들지 않는다. 마지막 구절 뒤에는 마지막이라는 안내와 원래 슬라이드로 돌아가는 버튼 설명을 보여준다. 기존 다음·이전 버튼을 그대로 쓴다.

**프롬프터**에서는 구절을 중심으로 읽는다. 세로 화면은 현재·다음을 위아래로, 가로 화면은 나란히 놓는다. 기존 글씨 크기 16~48 설정은 구절과 메모에 함께 적용된다. 길면 위아래로 밀어 읽는다. 기존 슬라이드 노트는 **이 슬라이드의 발표자 노트**를 펼쳐 확인한다. 구절 장면을 닫거나 다른 슬라이드로 가면 일반 노트 화면으로 돌아간다.

첫 등장 지연 중에는 아직 보이지 않는 글을 ‘현재 공개’라고 표시하지 않는다. 다음·이전·리셋·직접 클릭·탭 숨김/복귀와 재연결에서 실제 발표 상태를 다시 받는다. 연결을 다시 열어도 진행 명령을 재전송하지 않는다.

## 저장·메모 계약

- 선택 필드 **effect.sceneTracks[].teacherNote**: 글 트랙에만 허용, 앞뒤 공백 제거 후 최대 1000자. 키를 기준으로 연결하므로 등장 순서를 바꿔도 해당 구절의 메모가 유지된다. 기존 자료는 이 필드가 없어도 그대로 열린다.
- 문서 정리·저장·재열기, 타임라인 실행 취소/다시 실행, 프리셋 저장·불러오기·파일 왕복에 보존된다. 프리셋의 ‘현재 글에 움직임만 적용’도 메모는 함께 가져오므로 새 수업에 맞게 확인한다.
- 메모는 발표 화면/SVG/그림에 출력하지 않는다. 리모컨 링크를 가진 발표자에게 전달하며 링크를 학생 참여용으로 공유하지 않는다.
- HTML의 기존 **노트 넣지 않기 · 학생에게 줄 때**는 구절 메모도 제거한다. **함께 넣기**는 기존 슬라이드 노트와 같이 설정에 보존한다. 원래 자료의 메모는 지우지 않는다.
- 리모컨에는 지금과 다음 구절만 전달한다. 휴대폰 sessionStorage에는 시간/글씨/화면 설정만 저장하고 구절·메모는 저장하지 않는다.
- 새 DB·계정·유료 QA·AI 호출 없음. 기존 실시간 채널에 선택적인 cue 상태만 추가한다.

## 구현

cinema-layout.js에서 메모 정리/학생 HTML 제외, cinema-studio.js에서 구절별 작성, cinema-step-player.js에서 실제 공개된 구절 상태를 만든다. WeakMap 상태와 변화 이벤트를 사용하여 메모를 DOM 속성에 넣지 않고 매 프레임 네트워크 전송도 하지 않는다.

effect-player.js는 현재 장면 또는 아직 열지 않은 첫 장면의 상태를 읽는다. app/app.js는 현재 슬라이드만 리모컨 상태에 포함하고 구절 변경 이벤트를 기존 update 경로로 전달한다. 슬라이드 전환 도중 이전 장의 메모를 다음 장에 섞지 않는다.

가이랩의 onbatang-remote-protocol.js에서 길이·범위·허용 필드를 제한하고 onbatang-remote-view.js/.css/.html에서 표시한다. 공용도 기존 phone-remote → onbatang-remote-relay를 통해 같은 휴대폰 UI를 사용한다. 서버·SQL 변경은 없다.

## 검증과 제한

- cinema-cues 단위 검사: 메모 정리·프리셋 재열기·학생용 제외·원본 보존.
- html-effect-assets 브라우저 검사: 타임라인 UI 메모 입력 → 프리셋 저장/불러오기 → 문서 재열기 → 지연 전/후 현재·다음 메모 → 리셋 → 학생 HTML 메모 제외와 오프라인 재열기.
- cinema-remote-notes 브라우저 검사: 발표 창 + 실제 리모컨 UI 창 + 공용 iframe relay 또는 가이랩 showRemote를 로컬 BroadcastChannel로 연결. 공개 전/후·이전·직접 리셋·다른 장 이동·폰 창 재열기·연결 복구·메모 비노출, 390×844·844×390·320×568에서 최대 글씨와 고정 진행 버튼 확인.
- 가이랩 protocol/view 단위 검사: 잘못된 상태·길이 제한·메모 HTML 실행 방지·상태 수신 시 읽기 위치 보존·구절 변경 때만 읽기 위치 초기화·일반 노트 복귀.

브라우저 검수는 자체 제작 실과 구절 자료와 화면 에뮬레이션이다. 실제 휴대폰 QR 통신·화면 잠금·교사 계정·개인 PPT 검수는 이번 버전에서 별도 미실시. 로컬 BroadcastChannel 검사를 운영 Supabase 통신 검수라고 표시하지 않는다. 유료 QA는 사용하지 않는다.

최종 검사 수·commit·운영 배포 해시·보존한 변경은 작업 폴더 통합 인수인계에 기록한다.
