# 온바탕 인수인계 · 화면에서 장면 수정과 타임라인

2026-11-03 · 공용 0.122.0 · 가이랩 0.176.0

## 사용 흐름

글 조각 선택 → **시네마 효과 / 효과 수정 → 화면 · 타임라인 편집**. 갤러리에서는 다섯 시네마 카드의 **내 내용으로 꾸미기** 안에 같은 버튼이 있다.

- 화면의 구절을 두 번 눌러 직접 고친다. 선택한 문구 입력란으로도 수정할 수 있다. 숫자판은 부호·소수점·퍼센트를 포함한 최대 8자리 수치를 받는다.
- 끌어서 위치를 바꾸고 오른쪽 아래 손잡이로 크기를 바꾼다. 손잡이는 반대쪽 모서리를 기준으로 확대한다. 위치(%)와 크기(%) 입력도 제공한다. 선택 테두리에서 방향키로 1단위, Shift+방향키로 10단위를 움직인다.
- 타임라인의 화살표는 순서를 한 칸 바꾸고 전체 구절을 차례로 배치한다. 막대를 끌면 등장 시점, 오른쪽 끝을 끌면 움직이는 시간이 바뀐다. 숫자로도 시간을 정한다. 등장 뒤에는 화면에 남는다.
- 재생·멈춤과 재생 위치 막대로 같은 연출의 앞뒤 순간을 본다. **배치 편집**은 완성된 모습을 다시 표시한다. 실행 취소·다시 실행·선택한 부분 초기화를 제공한다.
- 편집기의 **슬라이드에 적용**은 기존 저장·실행 취소 경로로 반영하고 닫는다. 취소·Esc는 초안을 폐기한다. 갤러리의 **꾸미기에 반영**은 카드에 적용하며, 이 카드 초안은 새로고침 뒤 복구하는 문서 저장소가 아니다.
- 작은 화면은 미리보기를 남긴 채 **글 · 배치 / 타임라인**을 전환한다. 가로 휴대폰에서는 미리보기 옆에 설정을 배치한다.

## 지원 범위와 보존

| 효과 | 직접 고치는 부분 |
| --- | --- |
| 박자 오프닝 | 최대 세 구절의 문구·배치·크기·등장 시간 |
| 스포트라이트 | 제목과 무대 조명 |
| 롤링 숫자 | 숫자판과 설명 문장 |
| 종이 지평선 | 제목, 떠오르는 해, 종이 능선 |
| 탐사 항로 | 최대 세 단계의 문구·배치·시간. 각 단계의 길과 지점도 같은 시간에 맞춘다. |

원래 슬라이드의 글·위치·크기를 덮어쓰지 않고 **효과 안의 장면**을 편집한다. 기존 효과에 선택 필드 `sceneTracks`를 더하며, 값이 없는 자료는 원래 연출을 유지한다. 전체 효과 문구를 다시 입력하면 구절별 문구를 지우고 새 전체 문구를 따르되 배치·시간은 보존한다. 기존 ‘내 스타일’ 기능은 색감과 효과 전용 설정을 위한 기능이며, 이번 구절별 배치·문구 프리셋을 여러 개 보관하는 기능은 별도다.

PPT 원본, ID, 출처, 자산 소유권, 기존 PR을 변경하지 않는다. SQL·운영 DB·계정·유료 QA 사용도 없다. 새 연출은 온바탕 발표와 다시 내려받은 HTML 수업에 반영한다. PowerPoint 애니메이션이나 MP4 출력에 이 타임라인을 새로 매핑하지 않았다.

## 구현

- `src/cinema-studio.js`: 취소 가능한 편집 초안, 직접 입력·포인터 제어, 실행 취소, 순서와 시간, 프레임 재생, 반응형 편집 화면.
- `src/cinema-layout.js`: 효과별 키 허용 목록, 문구 72자, 위치 ±360/180 장면 단위, 크기 40~250%, 시작 0~30초, 길이 0.2~10초의 정리 규칙. 속도 설정이 있으면 화면의 실제 초에 환산한다.
- `part.layer`는 배치 transform을 애니메이션 그룹 바깥에 두어 움직임과 충돌하지 않게 한다. SVG clipPath의 직접 도형 조건도 유지한다. 발표, 갤러리, 관찰대, 오프라인 HTML이 같은 그리기·타이밍 정의를 쓴다.
- `cinema-controls.js`에서 공통 편집창을 열고, 편집기는 기존 적용 콜백으로 문서를 저장한다. 늦게 등장하도록 지정한 자동 효과는 재생 종료 시간도 연장한다.
- `build:pptx-import`, `build:html-lesson`으로 관련 번들을 갱신한다. 가이랩에는 확정된 원본 커밋을 `scripts/sync-onbatang.mjs`로 반영한다.

## 검증과 남은 항목

`tests/effect-scenes.test.mjs`: 값 제한·허용 키·중복 제거·기존 자료·HTML 표적 정리의 왕복 보존.

`tests/browser/html-effect-assets.test.mjs`의 `direct scene editing`: 갤러리 취소, 다섯 효과 직접 글 수정·위치·크기·시간 적용, 드래그와 모서리 조절, 실행 취소/다시 실행, 시간 막대 이동·길이 조절, 저장→새로고침→재열기, 발표 및 다운로드한 HTML을 오프라인 새 문맥으로 재열기. 원래 글이 바뀌지 않았는지도 대조한다.

`scene studio`는 390×844, 844×390, 320×740 터치 화면에서 문구·순서·재생과 화면 넘침을 검사한다. 기존 홈 경로의 자체 제작 4:3 PPT 2장 가져오기·저장도 회귀 검사에 포함한다.

실제 iPhone/iPad, 실제 교사 계정 동기화와 개인 수업 PPT 검수는 이번 검증에 포함하지 않았다. 브라우저 에뮬레이션과 실제 기기를 구분한다. 다음 개발 후보는 이름 붙인 장면 프리셋, 클릭으로 다음 구절 공개, 여러 슬라이드의 장면 연결이다.

최종 로컬 단위 검사 **414/414 통과**. Edge·Windows WebKit에서 직접 편집→저장→목록 복귀→새로고침→재열기→발표→오프라인 HTML 재열기와 위 세 가지 터치 화면 크기를 통과했다. 기존 PPT 홈 가져오기·효과·슬라이드 비교·질문·모션 세트 회귀도 확인했다. 초기 두 브라우저 동시 실행에서는 메모리 할당 실패/브라우저 닫힘이 있었고 단독 실행으로 해당 경로를 재검증했다. 모바일 순서 검사는 ‘한 칸 먼저’ 동작에 맞게 기대값을 수정했다. WebKit의 새로고침은 저장 후 목록 복귀를 확인한 다음 실행한다. 로그는 Git 제외 `work/studio-*.log`에 있다.
