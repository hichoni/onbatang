# 휴대폰 발표 리모컨 개선 — 2026-10-30

## 구현

가이랩 v0.157.0의 `onbatang-remote.html`, `onbatang-remote-view.js`, `onbatang-remote-view.css`를 개선했다. **공용 온바탕도 이 동일한 리모컨을 쓴다.** 공용 `app/phone-remote.js`는 `https://gbe.ai.kr/onbatang-remote-relay.html`을 통해 연결하고 가이랩은 직접 연결한다. 공통 편집기 원본은 v0.105.0 / `09eb31401389e4da3c935ad552dd110a96404bd5` / 252개 파일로 그대로 유지한다. 리모컨 UI를 내장본에 중복 복사하거나 직접 패치하지 않는다.

- 현재·다음 슬라이드와 노트를 읽는 영역은 스크롤되고, 활동 타이머와 앞·다음 버튼은 하단에 고정된다. 가로 휴대폰은 슬라이드와 노트를 나란히 놓고 오른쪽에 조작부를 고정한다. 작은 화면에서도 조작 버튼이 화면 밖으로 밀리지 않는다.
- 현재·다음 미리보기를 누르면 모달로 확대한다. 닫기/Escape로 돌아오며 발표 쪽을 이동시키지 않는다. 이것은 기존 축소 그림의 확대이며 원본 해상도를 다시 전송하는 기능은 아니다.
- 발표자 노트를 16~26px로 조절한다. 연결 확인 신호마다 노트 DOM을 다시 쓰지 않아 읽던 스크롤을 유지하고, 실제 장이 바뀌면 노트 맨 위로 돌아간다.
- 시간 설정·쪽 번호 이동·검은 화면을 접히는 도구 메뉴에 모았다. 기존 큰 버튼 모드와 교사 잠금·ACK·중복 명령 방지·오프라인/재연결은 유지한다.
- 타이머는 1·3·5·10분 또는 직접 입력한 정수 1~180분이다. 시작·멈춤·계속·1분 추가·초기화를 지원한다. 실행 중에는 시간 설정 입력을 잠가 실수로 초기화되지 않게 하고, 30초 이하와 종료 상태를 색과 글로 표시한다.
- 타이머는 마감 시각으로 계산하므로 탭이 숨겨져도 실제 지난 시간이 반영된다. 같은 탭에서 새로고침하면 타이머·사용 경과 시간·노트 글자 크기·큰 버튼 모드를 복원한다. 리모컨 코드별 sessionStorage에 이 설정만 최대 8시간 유효하게 보관하며 **슬라이드 그림·노트 내용·조작 명령은 저장하지 않는다**. 저장소 접근 불가/손상/오래된 값은 기본 설정으로 시작한다. 탭 종료·새 기기 간 타이머 공유를 보장하지 않는다.
- 타이머는 휴대폰에서만 돌아간다. 발표 화면·학생에게 타이머 명령을 전송하지 않는다. ‘리모컨 사용’ 시간은 수업 시작 시각이나 발표 PC의 경과 시간과 다르다.

## 검증

- 관련 단위 21/21: 리모컨 14개 + 공통 내장본/호스트 7개. 시간 입력 범위·pause/resume·1분 추가·새로고침 복원·만료 설정 무시·노트 위치·개인 자료 비저장·명령 중복/ACK/출처 방어를 포함한다.
- 로컬 Headless Edge 브라우저 3/3: 가이랩 실제 편집기→발표→리모컨, 공용 standalone→relay→리모컨, 새 휴대폰 UI 회귀. 네트워크는 localhost와 data/blob으로 제한하고 실제 Supabase 대신 일시적인 BroadcastChannel을 사용했다. 공용/가이랩의 기존 발표 화면을 실제로 넘기고 검은 화면·교사 잠금·오프라인 복구를 확인했다.
- UI 크기: 320×568, 390×844, 844×390, 768×1024. 가로 넘침 없음, 타이머·시작·앞뒤 버튼의 화면 내 좌표, 확대/Escape/포커스 복원, 직접 7분 설정과 1분 추가 후 새로고침, 노트 글자 크기 복원을 확인했다. 가로 화면의 노트 배치를 캡처 검토 후 다시 조정했다.
- 브라우저 캡처는 `g-ai-lab-inline/work/qa-remote-2026-10-30/phone-{320,390,844,768}.png`. 화면용 슬라이드는 직접 만든 검증 표본이다. 개인 수업 PPT나 학생 정보를 쓰지 않았다.
- `npm run build` 통과. 공식 `sync-onbatang ... --check`로 원본 commit·버전·252개 실제 바이트/SHA-256 일치.
- Windows 샌드박스에서 Edge가 실행되지 않아 허용된 별도 로컬 임시 프로필로 브라우저 검증했다. 처음 테스트 실패 중 나머지는 fixture 문자열 개행과 접힌 도구 메뉴의 테스트 진입 경로였고 수정 후 통과했다.
