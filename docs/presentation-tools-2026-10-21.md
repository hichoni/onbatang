# 발표자 노트와 발표 도구 · v0.34.0 (2026-10-21)

캔바·미리캔버스와 비교해 온바탕에 없거나 약했던 발표 기능을 보강했다. 온바탕이 지키는 원칙(가벼움, 바깥 라이브러리 없음, HTML 과의 호환, PPT → 가이X 앱 → 발표의 매끄러운 연결)에 맞는 것만 골랐다.

## 사용 방법

- **발표자 노트**: 꾸미는 화면의 그림 아래 **발표자 노트**를 펴서 적는다. 그림에는 나오지 않는다. 펴 둔 상태는 이 기기에 기억한다. 장마다 최대 5,000자.
- **PPT 노트**: PPTX 를 가져오면 각 쪽의 발표자 메모(노트 쪽의 본문 칸)가 그 장의 노트로 들어온다. 편집형 PPTX 로 내려받으면 PowerPoint 노트 창에 다시 들어간다.
- **발표 단축키**(온바탕 발표와 HTML 수업 공통, `app/show-keys.js`)

| 글쇠 | 하는 일 |
| --- | --- |
| → Space PageDown Enter N / ← PageUp Backspace | 다음 / 앞 |
| Home / End | 처음 / 마지막 쪽 |
| 번호 + Enter | 그 쪽으로 |
| G | 전체 보기(누르면 그 쪽으로) |
| B . / W , | 검은 화면 / 흰 화면(아무 글쇠나 누르면 돌아온다) |
| P / L / E | 펜 / 레이저 / 그린 것 지우기(쪽을 넘기면 지워진다) |
| S | 발표자 화면: 지금 쪽·다음 쪽·노트(글씨 크기 조절)·발표 시간 |
| K | 영상 멈추기·틀기 |
| ? H | 단축키 보기 |
| Esc | 켜 둔 도구를 먼저 끄고, 그다음 발표를 끝낸다 |

글자 글쇠는 자리로 견주므로 한글 입력 상태에서도 듣는다. Ctrl·Alt·Cmd 를 함께 누른 글쇠는 브라우저에 남긴다.

- **앱 쪽과 프레젠터**: 가이X 앱 안을 누른 뒤에는 글쇠가 앱으로 간다. 앱이 쓰지 않은 **PageDown·PageUp·Esc** 만 안전한 다리(bridge)로 발표에 알려서, 리모컨으로 계속 넘길 수 있다. 앱이 그 글쇠를 직접 쓰면(preventDefault) 넘기지 않는다. 글 입력칸 안의 PageDown·PageUp 은 넘기지 않는다.
- **HTML 수업**: 내려받기 → HTML 수업에서 **발표자 노트**를 고른다. 처음에는 **넣지 않기**(학생에게 줄 파일에 선생님 메모가 담기지 않게)다. 내려받은 파일의 **▶ 발표 모드**는 온바탕 발표와 같은 글쇠·도구·발표자 화면을 쓴다.
- **가이X 맥락**: 가이X 로 앱을 만들 때 참고로 고른 쪽(최대 3쪽)의 노트를 쪽마다 1,200자까지 함께 보낸다(흐름 전달 방식은 지금 쪽과 앞뒤 쪽 400자). 노트가 없는 쪽은 보내지 않는다.

## 구조와 계약

- 장(slide)에 `notes`(글) 하나를 더했다. `src/document.js` 의 `cleanNotes`·`slideNotes` 가 정리한다(조종 문자 제거, 줄바꿈·탭 유지, 빈 글은 저장하지 않음). `cleanDesign`·`slideExtra` 를 거치는 모든 저장·복사·재열기·비율 바꾸기에서 유지된다. 그림 요소가 아니므로 그리기·PNG·영상에는 영향이 없다.
- 편집기는 `api.notes`(접고 펴는 칸)를 내준다. 놓을 자리는 프로젝트가 정한다. 노트 입력은 그림의 되돌리기 기록과 따로다(입력칸 자체의 되돌리기를 쓴다).
- PPTX 내보내기: 노트가 있는 장만 `notesSlide` 를 만들고, 그때만 `notesMaster`·`theme2` 를 더한다. 노트가 없는 자료의 파일 구성은 이전과 같다. python-pptx 1.0.2 와 LibreOffice 로 노트가 읽히는지 확인했다.
- 발표 도구는 `app/show-tools.js` 하나다. 온바탕 발표(`app/app.js` 의 `present`)와 HTML 수업(`app/html-lesson-runtime.js`)이 같은 모듈을 쓴다. 모양(CSS)은 모듈 안에 들어 있어, 내려받은 HTML 과 발표자 화면 창에도 따라간다. 바깥 파일·네트워크를 쓰지 않는다.
- 발표자 화면은 같은 출처의 빈 팝업 창이다. 지금 화면의 CSS 규칙을 글로 옮겨 그린다. 팝업이 막히면 안내만 하고 발표는 계속된다.
