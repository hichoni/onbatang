# 온바탕 인수인계 · 시작 화면, 도구 분류와 발표 연출

## 다섯 효과 직접 수정 · 공용 0.121.0

글 조각을 고른 뒤 선택 속성의 **시네마 효과**로 시작한다. 적용한 글에서는 같은 자리에 **효과 수정**이 나온다. 휴대폰은 먼저 **속성**을 누른다. 갤러리에서는 각 카드 아래 **내 내용으로 꾸미기**를 연다.

문구와 강조색을 바꾸면 미리보기에 반영된다. 별도의 효과 문구를 쓰면 슬라이드 원문을 보존하고, 비워 두면 다시 원문을 따른다. 분당 박자, 스포트라이트 진행 방향, 숫자판 회전 칸 수, 능선 이동 폭, 탐사 구간 이동 시간(초)을 효과별로 조절할 수 있다. **꾸미기 초기화**로 원래 설정을 되찾는다.

**내 스타일 저장·불러오기**는 효과마다 색감·강조색·속도·전용 움직임 값 한 벌을 현재 서비스의 브라우저에 보관한다. 박자 오프닝의 속도는 BPM으로 정한다. 다른 글에서 불러와도 그 글의 문구를 쓴다. 자료에 반영하려면 **고른 조각에 적용**한다. `cinema-controls.js`를 편집기와 갤러리가 공유하며, 선택 필드는 효과 정리·자료 저장·발표·오프라인 HTML에서 같은 규칙을 따른다. 운영 DB 변경은 없다.

검수 경로는 `tests/browser/html-effect-assets.test.mjs`의 `home starts either`다. 갤러리에서 스타일 저장 후 초기화, 편집기에서 불러오기, 원문 보존, 다섯 효과 수정, 재열기와 오프라인 재생을 확인한다. 390px 터치 에뮬레이션에서 속성 열기·스타일 불러오기·적용을 확인했다. 실제 기기와 계정 간 동기화는 검수 범위 밖이다.

## 교사가 사용하는 경로

- **새 자료 만들기**는 빈 16:9 편집판을 연다. **PPT 가져오기**는 같은 첫 화면에서 기기의 PPTX 선택기를 연다. 파일을 고르면 쪽·글꼴 확인 화면에서 편집까지 이어지고 취소하면 홈에 머문다. 새 자료 만들기와 가져오기는 각자 원래 비율·저장 방식을 따른다.
- 편집기 상단의 **추가**에서 글과 꾸미기(도형·그림·차트·수식), **자료**에서 사진·PPT·영상·웹, **디자인**에서 틀·바탕색·겹 순서·움직임을 고른다. 그룹은 마지막에 사용한 세부 도구를 기억한다. 장 목록과 선택 속성, 작은 화면의 접기와 터치 제어도 이어진다.
- **글 조각 선택 → 디자인 → 움직임 → 그래픽 효과 → HTML 그래픽 효과**로 들어간다. 효과를 고르고 **고른 조각에 적용**하면 도구를 접고 편집으로 돌아온다. 발표와 내려받은 HTML 수업에서 재생한다.

| 연출 | 입력과 동작 |
| --- | --- |
| 박자 오프닝 | 글의 첫 72자에서 최대 세 구절을 얻는다. 줄바꿈으로 구절을 정하고 한 줄이면 낱말을 묶는다. 분당 60~180박을 정하면 한 박자마다 다음 구절이 올라온다. 120 BPM이면 구절 간격은 500ms다. |
| 스포트라이트 타이틀 | 실제 제목을 줄에 맞춰 놓고, 왼쪽에서 오른쪽으로 움직이는 빛이 글과 하단 선을 드러낸다. |
| 롤링 숫자 | 글에 적힌 첫 수치의 자릿수가 굴러 목표값에서 멈춘다. 최대 숫자 8자리이며 부호·소수점·퍼센트를 표시한다. 아래에는 원래 문장을 함께 둔다. |

갤러리에서도 제목·BPM·수치 문장을 바꿔 볼 수 있다. [박자 오프닝](https://onbatang.web.app/app/effects.html#beatintro) · [스포트라이트](https://onbatang.web.app/app/effects.html#spotlighttitle) · [롤링 숫자](https://onbatang.web.app/app/effects.html#rollingnumber)

## 영상 참고와 구현 범위

AI점프 영상의 공개 장면 미리보기와 설명에서 발표 대사, 큰 수치, 박자에 맞춘 장면 전개를 확인했다. 빌더 조쉬 쇼츠와 제작자가 연결한 MotionSites의 기법 목록에서 제목 등장과 스포트라이트를 참고했다. 온바탕의 자체 SVG·요소 효과·오프라인 재생 경로로 제작했다. [AI점프 발표 오프닝](https://youtu.be/P8xFj-49dzA?t=121) · [빌더 조쉬 쇼츠](https://www.youtube.com/shorts/nWrk7Z001h4) · [MotionSites 기법 목록](https://github.com/Motionsites-AI/claude-skill)

이번 박자는 교사가 지정하는 무음 시각 연출이다. 음악에서 박자를 분석하거나 음성 인식·AI 영상 생성 요청을 실행하는 기능은 포함하지 않는다. 새 요소 효과의 출력 검수 범위는 온바탕 발표와 오프라인 HTML이다.

## 저장과 호환

기존 탭 ID와 편집 명령을 세부 도구로 사용하고, 단순 임베드 편집기의 기존 탭을 유지한다. 홈 파일 선택은 지원 호스트가 `importAction.homeFile`을 제공할 때만 노출한다. 실제 File과 inline 문맥을 기존 가져오기 서비스에 넘기며, 변환·원본 보관·자산·여러 파트 저장·진행 중 재시도 보호를 재사용한다. 앱 원본과 기존 문서 형식은 유지하고, BPM은 해당 효과만 가지는 선택 필드다. SQL·운영 DB·계정·유료 QA 변경은 없다.

## 확인 및 다음 작업

공용 전체 단위 검사 412개 통과. 로컬 Edge·Windows WebKit에서 새 자료·홈 파일 선택 취소·4:3 표본 2장 가져오기·기존 자료 열기·글에 연출 적용·저장 후 재열기·발표·오프라인 HTML 재생을 검사했다. 상단 메뉴를 열고 닫으면서 1440/932/390/320px에서 기존 슬라이드 위치와 크기를 대조했다. 기존 인라인 가져오기 취소·부분 저장 재시도·터치 보호도 확인했다.

재현 시험은 `tests/browser/page-workspace.test.mjs`, `tests/browser/inline-pptx.test.mjs`, `tests/browser/html-effect-assets.test.mjs`의 `home starts either` 및 `element effects survive`이다. 새 테스트는 실제 사용자 메뉴를 통해 세부 도구를 연다. 가이랩에는 확정된 공용 커밋을 `scripts/sync-onbatang.mjs`로 동기화한다.

실물 iPhone·iPad, 실제 계정 동기화, 교사 개인 PPT 및 MP4/PPTX의 새 연출 출력은 이번에 검수하지 않았다. 다음 V2 기능은 선택 속성의 기본·고급 구분과 목적별 내보내기다.

11월 3일 두 운영 주소에서 Edge의 새 브라우저 프로필로 홈의 파일 선택→4:3 두 장 가져오기와 별도 기존 자료에 세 가지 연출 적용→저장·재열기→발표→오프라인 HTML 재생을 확인했다. 운영 갤러리의 프레임을 대조하다가 스포트라이트의 밑줄만 밝아지고 글자가 회색으로 남는 문제를 발견했다. 0.119.2에서는 SVG 클리핑 영역의 직사각형을 직접 움직이도록 수정했다. 발표·HTML 회귀 검사에서 이 도형이 클리핑 영역의 바로 아래에 있는지도 확인한다.

## 시네마 효과 0.120.0

2026-11-03 후속. 공용 0.120.0과 가이랩 0.174.0이 같은 다섯 장면을 사용한다. 편집기에서 **글 조각 → 디자인 → 움직임 → 그래픽 효과 → HTML 그래픽 효과 → 고른 조각에 적용**을 누른다.

- **박자 오프닝**은 지정한 BPM에 맞춰 레코드 홈의 호와 각 구절이 들어온다. **스포트라이트 타이틀**은 빛의 가장자리, 광선, 제목, 밑줄을 같은 시간축에 놓았다. **롤링 숫자**는 0을 포함한 모든 자릿수가 독립적으로 회전한 뒤 작은 반동과 함께 멈춘다.
- **종이 지평선**은 해와 네 겹의 능선이 서로 다른 거리로 이동한다. **탐사 항로**는 줄바꿈으로 구분한 최대 세 구절을 경로에 대응시킨다. 선과 움직이는 표식은 같은 곡선을 따르고, 도착한 지점의 번호는 계속 보인다. 갤러리 상단에서 다섯 효과로 바로 이동할 수 있다. [종이 지평선](https://onbatang.web.app/app/effects.html#paperhorizon) · [탐사 항로](https://onbatang.web.app/app/effects.html#fieldroute)
- 기존 세 효과의 ID, BPM·색감·재생 시점·관찰 지점과 문서 형식을 유지했다. 이전에 내보낸 HTML에는 당시 재생기가 내장돼 있으므로 새 연출을 담으려면 원래 자료에서 다시 내려받는다.
- 검수 경로는 `tests/browser/html-effect-assets.test.mjs`의 홈에서 4:3 두 장 가져오기, 다섯 조각에 효과 적용, 저장·재열기, 발표·오프라인 HTML 재생 및 모바일 관찰대 되감기다. 실물 iPhone·iPad와 계정 동기화는 별도 검수 대상이다. 운영 DB 변경이나 유료 QA 사용은 없다.
